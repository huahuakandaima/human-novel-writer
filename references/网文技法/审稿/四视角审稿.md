# 四视角审稿（改编自 oh-story story-review）

> 来源：oh-story-claudecode `skills/story-review`（已去工程化：无 reviewer agents、无脚本依赖，四个视角由主线程串行执行）
> 用途：对正文章节做多视角对抗式审查。**执行铁律：审查是找问题，不是验证正确性。**

## 平台 rubric 选择

按目标平台选评分标准（`审稿/rubrics/` 下）：
- `rubrics/fanqie.md`（番茄）、`rubrics/qidian.md`（起点）、`rubrics/zhihu.md`（知乎盐选）
- 无明确平台 → 用 `审稿/quality-rubric.md` 的通用网文 rubric
- 文件不可读时用下方内置基准包（不许降级为"无标准审查"）

## 四个视角（主线程依次执行，每视角独立过一遍再汇总）

### 视角 1：架构师（结构/节奏/期待）
- 章节是否围绕明确卖点推进；看不出卖点 ≥ S2
- 冲突推进：是否有阻碍、选择、代价或关系变化；只解释/闲聊/总结 ≥ S2
- 钩子与期待：开头或结尾是否制造后续问题；无悬念 ≥ S2
- 剧情循环：目标→阻碍→行动→代价/反馈→新期待；缺目标/阻碍/反馈 ≥ S2
- 高潮构建：蓄能→假胜→崩解→反转/兑现；平铺无代价 ≥ S2/S3

### 视角 2：人物（动机/关系/一致性）
- 角色动机：行为是否符合目标、性格、处境和关系压力；为剧情服务而失真 S1/S2
- 关系进展：互动尺度必须匹配当前关系阶段；越界亲密/突然信任/突然敌对需铺垫，否则 S1/S2
- 人物失忆/越权/写偏（对照角色卡与追踪文件）

### 视角 3：叙事（文字/对话/视角）
- 对话质量：是否有潜台词、信息控制、角色差异；说明书式对话 ≥ S2
- 文字自然度：具体可感、动作承载信息；AI 腔/陈词滥调/总结体按影响定 S2/S3
- 句长节奏：叙述默认逗号长句；碎句电报体与 AI 腔同级（不因「短=网文节奏」放行）
- 标点节奏：标点是否服务语气/人物声线；通篇句号化/随机堆感叹号按影响定 S3/S2
- 视角一致性：是否混入上帝视角（对照「普通人视角铁则」）

### 视角 4：一致性（设定/伏笔/时间线）
- 设定一致性：不违背已写规则、时间线、角色属性；明确事实冲突通常 S1
- 伏笔状态：可追踪；新开伏笔是否登记、旧伏笔是否推进/回收
- 数字/时间/资源权限：是否与追踪四件套一致（对照 `追踪/` 文件）

## 汇总报告

按平台 rubric + 四个视角的 findings 汇总，每条 finding 必须：
1. 有原文证据（引用具体句子/段落）
2. 给出可执行修改方向（不只说"有问题"）
3. 按本 skill 的 S1/S2/S3 分级：S1 必须清、S2 必须清零、S3 尽量清

报告结构：
```
【审查对象】书名·第NNN章
【平台 rubric】fanqie/qidian/zhihu/通用
【S1 必清】…（引用+问题+改法）
【S2 必清零】…
【S3 建议】…
【亮点】本章最值得保留的 1-2 处
```

## 内置基准包（rubric 文件不可读时必用）

- 核心卖点 / 冲突推进 / 任务卡点（卡出信息关系代价选择，只剩流程细节 ≥ S3）/ 情绪曲线（平直或突兀 S2/S3）/ 钩子与期待 / 开头新鲜度（套路化开局 ≥ S3）/ 角色动机 / 对话质量 / 设定一致性 / 文字自然度 / 句长节奏 / 标点节奏 / 格式可读性 / 剧情循环 / 高潮构建 / 关系进展 / 伏笔状态（密度只作结构风险提示，不直接升级 S2+）
- AI 味速查：高频套话（命运的齿轮开始转动/心猛地一沉/眼神复杂/踏上新的旅程）、章末总结体（这一切都说明…/他终于明白…）、信息倾倒、论文体连接词（然而/与此同时/不可否认）。处理原则：有原文证据才输出 finding；修法方向不默认「拆短/删虚词/剥标点」——把正常逗号长句拆成碎句与 AI 腔同样是问题。

## 与主工作流的衔接

- 挂在每章 8 步循环的 REVIEW 步骤之后：作者冷读（单人）→ 四视角审稿（如需深度审查，用户说「审一下」时调用）
- 审稿结论与 `追踪/` 联动：S1 一致性 findings 回写伏笔/时间线差异
