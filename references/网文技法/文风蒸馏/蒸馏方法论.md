# 文风蒸馏（改编自 writing-dna-skill）

> 来源：`larashero3-dotcom/writing-dna-skill`（六层蒸馏方法论，已适配本项目：产物落点改为 `文风库/{作者名}/`）
> 用途：把任意作者/账号的一批文章蒸馏成可复用的 Writing DNA，写作前重读 DNA 即可稳定复刻风格。
> **重要边界**：用于学习、分析、风格研究和个人写作资产沉淀；不得冒充作者本人、误导读者或侵犯版权。语料须为用户合法持有或有权使用的文本。

## 适用场景

- 分析某个作者/账号的稳定写作风格（含网文作者）
- 沉淀自己的写作风格资产
- 对标书拆完后，把对标作者的文风蒸馏成基线（与拆文对标联动）
- 给 AI 提供更稳定的风格复刻上下文

## 语料要求

- **至少 20 篇完整文章**（文件 `.md` 或 `.txt`），覆盖不同时期/主题/类型
- 存到 `文风库/{作者名}/raw/`（或 `raw-corpus/`）
- 命名：`YYYY-MM-DD 内容类型 文章标题-来源.md`

## 六层蒸馏（产物模板见 `文风蒸馏/模板/`）

| 层次 | 分析对象 | 产物 |
|---|---|---|
| L1 表层语言 | 词频、句长、标点、修辞、常用表达、中英混用习惯 | `语言DNA.md` |
| L2 文章结构 | 开头 hook、正文架构、转折方式、结尾收束 | `文章结构模板.md` |
| L3 选题逻辑 | 发布时机、切入角度、话题优先级 | `写作视角与认知框架.md` |
| L4 素材策略 | 引用来源、权威对象、案例和数据使用方式 | `写作视角与认知框架.md` |
| L5 认知框架 | 世界观、价值判断、核心假设、反复出现的命题 | `写作视角与认知框架.md` |
| L6 视觉风格 | 配图策略、排版格式、字体层级、色彩（网文通常无图，跳过） | `视觉风格指南.md` |

L1-L2 解决「怎么写」，L3-L5 解决「怎么想」，L6 解决「怎么呈现」。只复刻语言会「读着像但想法不像」，只复刻结构会「框架像但语气不像」。

## 蒸馏流程（6 步）

1. **收集语料**：≥20 篇完整文章入 `raw/`
2. **元数据标注**：每篇按 `模板/_meta-schema.json` 标注（title/date/type/topic_tags/hook_type/structure_pattern/word_count）
3. **分析语言 DNA**（L1）：统计词频、句长、标点、段落节奏、常用表达 → `语言DNA.md`（用脚本式分析，不凭感觉）
4. **提炼结构模板**（L2）：标注开头/转折/正文组织/结尾方式，不同文章类型各整理一套 → `文章结构模板.md`
5. **归纳认知框架**（L3-L5）：深度阅读提取选题逻辑、素材偏好、价值判断、核心假设、反复命题 → `写作视角与认知框架.md`
6. **整理视觉风格**（L6，有图才做）→ `视觉风格指南.md`；最后整合全部产物 → **`Writing-DNA.md`**（总入口，写作前最常读这份）

## 使用蒸馏产物（写作前）

1. 布置写作任务，给足选题上下文
2. **重新阅读全部蒸馏产物**（尤其 `Writing-DNA.md`、`语言DNA.md`、`文章结构模板.md`、`写作视角与认知框架.md`）
3. 按产物中的语言/结构/认知规则写作
4. 输出不像时：对照各层产物逐项自检后重写，不靠模糊感觉

## 与主工作流的衔接

- 写正文时用户说「按 XX 作者的风格写」→ 查 `文风库/`，有该作者 DNA 则按第 2 节流程使用；没有则先蒸馏
- 拆文对标 + 文风蒸馏联动：`拆文库/{书名}/文风.md` 是单本书的文风视图；`文风库/{作者}/Writing-DNA.md` 是该作者跨书风格基线，日更时可叠加使用
- 蒸馏的六层清单可复用于「活人感写作」自查：把「语言指纹」从感觉升级为可查的 DNA 文件
