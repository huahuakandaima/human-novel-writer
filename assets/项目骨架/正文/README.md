# 正文/README.md

> **正式正文**只放在这里。未通过你本人确认的稿，绝不放进此目录。

## 命名规范
- 文件名：`第NNN章-章节名.md`
- NNN 三位补零：`第 007 章`、`第 038 章`、`第 200 章`
- 章节名短而具体，不要用华丽辞藻做章节名

## 写一章的固定顺序（与 10/12 的 8 步循环对应）
> 1. **LOAD** 从 `00-项目状态.md` 的"本次必读"清单按顺序读
> 2. **CHECK** 写前检查——冲突 / 缺失 / 时间 / 资源 / 权限
> 3. **CONTRACT** 在 `大纲/滚动细纲-NNN-MMM章.md` 填写"章节合同"11 问
> 4. **DRAFT** 写初稿（按场景写，不把细纲逐渐扩句）
> 5. **REVIEW** 冷读——只读正文，不读脑补
> 6. **REVISE** S1 / S2 必须清零再标完成（S3 尽力清）
> 7. **UPDATE** 把变化回写到 `追踪/` 三表 + `00-项目状态.md`
> 8. **DECIDE** 交由你本人裁决——这才算真正完成

## 待确认稿的位置
- 路径：`待确认/审核与复盘/`
- 命名：`YYYYMMDD-HHmm-章节名-待确认.md`
- 通过冷读 + 你本人裁决后，从 `待确认/` 移入 `正文/`，本目录删除

## 单点事实源
- 同一章只有一份文件，不允许有两个"最新版"
- 推翻旧稿时立刻把旧版本搬到 `待确认/审核与复盘/`，**禁止原地覆盖**
- 同一章多轮重写时，旧版待确认稿加版本后缀留档（如 `20261007-2144-章节名-待确认-v1朱雀74.5.md`），供复盘对照；未被推翻的中间版可不留

## ⚠️ 严禁
- 在正文里出现任何 `[TBD]`、`[TODO]`、`[待补]` 之类的占位符
- 在本目录留任何"待改"标记
- 把章节正文分散到多个文件
