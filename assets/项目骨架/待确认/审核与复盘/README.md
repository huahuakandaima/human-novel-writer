# 待确认/审核与复盘/README.md

> 两类文件并存：
> 1. 章节级的"待确认稿"——未通过你本人裁决的版本
> 2. 滚动复盘——每写完 5~10 章做一次

---

## 1. 待确认稿

- 命名：`YYYYMMDD-HHmm-章节名-待确认.md`
- 文件头标注：`状态：待确认 / 待解决的问题：...`
- 通过冷读 + 你本人裁决后：
  1. 把定稿移入 `正文/第NNN章-章节名.md`
  2. 把本目录里的待确认稿删除（**禁止原地覆盖**）
  3. 在 `00-项目状态.md` 更新"最近一次确认"日期

### 待确认稿正文模板
```
---
状态：待确认
待解决的问题：
- 问题 1：
- 问题 2：
冷读责任人：_待填_
裁决日期：_待填_
---

# 第 NNN 章 章节名（待确认稿）

（正文从这里开始）
```

---

## 2. 滚动复盘

每写完 5~10 章，做一次：
- 命名：`复盘-第NNN-NNN章.md`
- 模板见下方

### 复盘模板
```markdown
# 复盘：第 NNN - NNN 章

## 保留
> 这段时间哪些决策有效，下一阶段继续做
- _待填_

## 停止
> 哪些套路 / 节奏 / 角色行为造成读者疲劳或偏离
- _待填_

## 试验
> 下一阶段要试的新决策（表达 / 结构 / 节奏 / 角色动作）
- _待填_

## 数据观察
> 留存 / 完读率 / 章节阅读时长 / 评论区反馈（如果有）
- _待填_

## 资源与权限回顾
> 这段时间资源 / 权限 是否显著偏离设定
- _待填_

## 伏笔健康度
> 仍在潜伏的伏笔数量、灭火清单里新增了几个
- _待填_
```

---

## ⚠️ 时序
> 复盘永远在新章节开写之前完成。否则"滚动复盘 → 试验新动作"的回路失效。
