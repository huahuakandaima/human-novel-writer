### 7.1 环境描写必须「有用」（基础纪律）

写景只干四件事，**写不出功能就删掉**：

1. 交代可利用的空间 / 规则
2. 承担情绪（推开出租屋的门，屋里黑漆一片，只有冰箱在响）
3. 暗示危险等级（天空阴沉，反常的黑色飞雪从天而降）
4. 制造人物关系（环境成为情感容器）

**把景物写活**：景物 + 喻体 + 喻体的动作。

>华丽的吊灯沉睡着，灯下红木长桌伫立在会客厅的中心，门前倚着一个晒太阳的……镜子。
>
> 唯有这淤泥中的古老宝石还散发着微弱的荧光，宛如呼吸般，以一种极为缓慢的速率明暗变化。

**感官优先级**：视觉 > 听觉 > 嗅觉 > 触觉 > 味觉。写景占篇幅 8%~12%，是配角。

**例外**：如果某个感官对角色是「失而复得」的，它值得写重。

**两条硬纪律**：

1. **独立成段，绝不夹在对白中间。**「对白 → 环境 → 对白」出现 0 次。
2. **主语是景物，不是人。** 九成以上的环境句以景物开头；用人称只做「视点锚定」，且人必须在句首或句尾。

**长度 = 感官通道数 × 15~20 字**：1 通道 15~30 字（转场），2 通道 30~60 字（主力），3 通道 60~90 字，且末尾必须落一个身体词或情绪词。

**感官配比**：视觉独占五成，其余零星补位；要加第二个通道时，优先加**嗅觉或温度**。

**喻体纪律**：只能取自主角「见过、摸过、吃过」的物质层（水、食物、常见兽、随身武器、日用器物），**不用抽象概念**（不写「时间如潮」「悲伤如影」）。

**拟人只给动作，不给情绪**：沉睡、吞噬、拖入、握碎可以，「孤独的灯塔」不行。

**落点纪律**：环境句最后必须有东西接着——人物的一个动作、一个声音、一种感受。接不上就重写。

### 7.2 篇幅与架构：写多长、写多密、怎么成组

**单位是「一句」，不是「一段」。** 连续环境句的「块」里，90%~97% 只有 1 句。

**密度是配角。** 独立环境句实测占全部句子 0.2%~1.6%，**每章 0.5~1 句**（场景切换那一章可以给 2 句）。

> ⚠️ **两个口径别混算**：7.1 里「写景占篇幅 8%~12%」算的是**字符篇幅**（含顺手捎在动作里的环境词）；这里算的是**独立成段的环境句条数**。写作时按条数执行即可，不必去凑篇幅百分比。

**「一句」是下限，常态是「两句一组」**：**54.6% 的环境句后面紧跟着另一句环境**；而「连着三句以上都在写景」在样本中出现 **0 次**。

成组只有一条结构，背下来就够用：

> **第一句静，给尺度与色调；第二句动，给一个能摸到的东西，或一个变化。**
> **一块（两句）里只给一个变化：声 / 光 / 味 / 人，四选一。**
>
> 四周是一座座燃烧的火盆，将广场内照得毫无阴影。
>
> 而在会场周围，是一层层看不到尽头的人，宛如海洋一般，那一双双各色的眼瞳倒映着火光。

**战斗 / 异变专用的五种推进式**（仍是一块两句，只是第二句在「推进」）：

| 式 | 例 |
|---|---|
| 数量级潮水推进 | 数不清的黑影从岩石缝隙、地底洞穴中钻了出来，如同黑色的潮水般涌向车队！ |
| 声音推进 / 声音缺席 | 空气中只有死一般的寂静，仿佛连风都停止了流动。 |
| 光线推进 / 吞噬 / 切割 | 原本明亮的灯光被无尽的黑暗吞噬。 |
| 温度推进 | 周围的空气被烧得噼啪作响，甚至连坚硬的黑曜石地板都开始呈现出融化的液态！<br>**都市版**：柏油路面被晒得发软，鞋底踩下去会留下一个浅浅的印子。 |
| 「突然」式局部突变 | 周围原本平静的雪地，突然像是沸腾的水面般，剧烈翻滚起来。 |

### 7.3 起笔：六种开头

| 起笔 | 频率 | 公式 | 例 |
|---|---|---|---|
| 处所方位起笔 | ~13% | `[处所] + [方位/结构] + [状态]` | 房间的楼道不同于刚才的卧室，有着一股阴凉的气息。 |
| 人物动作带出（视点锚定） | 7.1% | `[人物] + [站/坐/走] + [视线落到的景]` | 她此刻在旅馆的二楼，坐在敞开的窗户旁，看着远处的市集。 |
| 天气天象起笔 | 5.1% | `[天色] + [一个突然的天气动作] + [来源]` | 灰色昏暗的天空爆闪一次，然后隐约的雷声从遥远的天际传来。 |
| 时间词起笔 | 3.3% | `[时段] + [空间] + [残留的光/温度]` | 傍晚的要塞上，砖石依然残留着阳光的温热。 |
| 小器物特写起笔 | 2.8% | `[一个物件] + [材质细节]` | 两只火把插在墙壁上，安静地燃烧。 |
| 听觉起笔（最少，但最辨识） | 1.7% | `[声音] + [由远及近的路径]` | 转过昏暗的走廊，随着向厨房靠近，逐渐能听到热闹的声音。 |

### 7.4 骨架：八型句式

| 型 | 公式 | 干什么用 | 例 |
|---|---|---|---|
| ① 时间天气 | `[时段/天色] + [空间主体] + [光/天气状态]` | 交代场景、定调 | 天空也越来越暗，越来越沉，明明是正午时分，却仿佛临近黄昏一般。 |
| ② 俯视全景 | `[俯瞰/下方] + [数量级] + [大范围地貌] + [整体比喻]` | 宏大场景、施压 | 大量的灯火点缀在大地上，从天空俯瞰，宛如橙黄的灯火海洋。 |
| ③ 视线由远及近 | `[远景] → [中景] → [近景落点]` | 移动中的空间交代 | 看着下方那青翠的树海，将视线继续拉远，天际的尽头处似乎是树木稀疏的原野。 |
| ④ 光影落点 | `[光源] + 透过[遮挡物] + 落在[表面] + [表面变化]` | **最常用型**（含「光」字的句子占 24%） | 余晖被树木一根根分开，在地上形成错落的光和影。 |
| ⑤ 气味入鼻 | `[气味源] + [香/臭词] + 风作介质 + 钻入鼻子 + [身体反应]` | 感官定位 | 空气中有股青草的香味，随着和煦的微风钻入鼻子中，有时会微微的发痒。 |
| ⑥ 声音衬静 | `[极小/唯一的声源] + 只有/唯有 + [极静的环境]` | 用小声音放大安静 | 直到最后，这片桦树林中再也没有声响，连天空喧嚣的鸟鸣也在此刻寂静下来。 |
| ⑦ 动态场景 | `[风/雨/火/根] + [动词链] + [受动体] + [结果]` | 危险暗示 | 一道闪电撕裂天空，炸裂的雷声在群山间响起，豆大的雨滴争先恐后地坠落，击打在屋檐、窗户与树冠上。 |
| ⑧ 静态陈设罗列 | `[处所] + [物件A、B、C] + [数量词]` | 快速过场 | 房屋内被墙壁简单分隔为三块，中间是大厅和餐厅，摆着桌椅，一旁还有柜子。 |

**⑧ 附带的「尺度锚定」技巧**（大空间 / 奇幻必备）：拿日常物给奇观定标。

> 直径约有一个篮球场大。

### 7.5 功能：七种功能，答不出来就删

7.1 的「四件事」是准入门槛（能不能写）；这里是**分型**——每型都有触发条件 + 公式，写作时直接对号：

| # | 功能 | 触发条件 | 公式 |
|---|---|---|---|
| 1 | 场景定位 | 场景刚切换、开章 | `[地标/建筑] + [结构] + [人的量级]` |
| 2 | 气氛压迫 | 进入危险 / 封闭空间 | `[封闭体] + [无光/无出口] + [异响]` |
| 3 | 异变预告 | 规则被打破的前一秒 | `[本应正常的事物] + 突然 + [反常动词]` |
| 4 | 战斗铺底 | 大规模动作发生前 | `[数量级] + [运动方向] + 喻体（潮水/海啸）` |
| 5 | 情绪外化 | 情绪到临界点 | `[天气/环境] + 停在对人物身体上` |
| 6 | 感官冲击 | 情色 / 大场面 | `[味1] + [味2] + [味3] + [侵入方向]` |
| 7 | 收尾余味 | 场景结束 | `[天空/远景] + [一个持续的动作]` |

**绑定度**（书B 220 句全量手工分类）：战斗 + 情色 ≈ 43%，加上压迫 + 异变 ≈ **84% 的环境句出现在「有事情正在发生」的场景里**——环境句从不独立存在，它是**容器**，正文内容往里倒。即便是休息场景（泡澡、温泉、扑进大床），也照样挂一个感官评价收尾。

另有约 **8%** 是**吐槽体劫持**（句中插一个笑点：他的心就像在阳光下暴晒了三天的雪糕，早就化得连渣都不剩）。写法见 5.1。

### 7.6 融入：三种载体，按文体选（选错就像抄错了书）

| 载体 | 做法 | 适用 | 成本 |
|---|---|---|---|
| **A 独立成段的景物句**（书D 主力） | 一整段就是景物（7.1 讲的都是这种） | 空间大、史诗感、冒险、战斗 | 密度必须最低，效果最强 |
| **B 人体化的环境句**（书B 专属） | 环境与身体互相改写，见下表四种做法 | 场面强、情绪重、情色 | 辨识度最高 |
| **C 挂在动作句上的环境短语**（书C 专属） | 环境降级成动作句里的**状语**，不独立成段 | 现代都市、室内日常、对话密、段落短 | 均长只有 27 字，不打断节奏 |

**载体 B 的四种做法**：

| 做法 | 说明 | 例 |
|---|---|---|
| 身体溢出成环境 | 把人的气息写成填满房间的东西 | 一股难以言喻的甜腻香气，像盛开到极致的花蕾，又像发酵醇厚的蜜酒，顺着她的毛孔缓缓溢出，无声无息地填满了整个卧室。 |
| 环境改写身体 | 环境是动词的施动者 | 他感觉自己仿佛掉进了一个滚烫的熔炉，四周的空气变得粘稠且灼热，身体也变得躁动不安。<br>**都市版**：他感觉自己被塞进了一辆夏天暴晒过的车，椅面烫得隔着一层裤子都难受，空气又闷又稠。 |
| 心理物理化 | 情绪 = 天气 = 食物 | 他的心，就像在阳光下暴晒了三天的雪糕，早就化得连渣都不剩。 |
| 体型写成天象 | 人即灾难 | 整个身影如同一座巍峨的黑山般压了下来。 |

**载体 C 的例**（言情 / 都市的默认档）：

> 高跟鞋落地的瞬间，楼道里的声控灯一层层亮起来，又在她身后一层层灭掉。
>
> 厚重的防盗门在身后关上，把楼道里的冷气、邻居家的电视声一起隔在了外面。
>
> **选型判据**：空间大、跨度长 → A；场面强、情绪重 → B；场景小、对话密、段落短 → C。
> 三样可以混用，但**一章之内不要换载体**。

### 7.7 时机：什么时候该出现

按**功能**分三档（不是按「写在章首还是章尾」）：

| 时机 | 例 |
|---|---|
| 场景刚切换 | 转过昏暗的走廊，随着向厨房靠近，逐渐能听到热闹的声音。 |
| 人物停顿喘息 | 窗外的山林飘着雪，房间里一片温暖。 |
| 战斗 / 异变 | 沉寂的夜晚，突然，危急而紧张的钟声在城中各处响起，到处都是呼喊的声音。 |

**密度由「场景切换频率」决定，不由文笔决定**：换地点勤（旅店 → 市集 → 草原 → 山谷），每换一次就得给一次空间锚点；连续多章都在同一栋房子里（读者早知道「这是哪儿」）、没外出、没变天、没战斗时，**可以整章 0 句**。7.1 给的「每章 0.5~1 句」是平均值，不是下限。

### 7.8 加料：拟人 / 通感 / 气味三叠

**拟人只给动作**（7.1 讲过「不给情绪」，这里是动作菜单）：睡眠、呼吸、重量、捕食、奔跑、拖拽、人体动作、人的劳动。

| 给谁 | 给了什么动作 | 例 |
|---|---|---|
| 天空 | 重量 | 天压得很低，好像随时会落到楼顶上。 |
| 黑暗 | 捕食 | 楼道里的黑像有什么东西，一点一点把最后那点灯光吃掉。 |
| 烟雾 / 水汽 | 奔跑 | 锅盖一揭，白汽腾起来，在半空散成各种形状，像有东西在里面奔走。 |
| 植物 | 拖拽 + 掩埋 | 楼下的爬山虎顺着墙缝一路爬上去，把整面墙一点点填死。 |
| 器械 | 人体动作 | 吊车的长臂凌空一握，把那截钢筋捏成了一团。 |
| 声音 | 人的劳动 | 在喧闹的夏夜里扫出一小片安静来。 |

**通感只走两条轴**：

- 轴一 **视觉 ↔ 触觉 / 温度**：正午的柏油路面反着白光，白得好像能把眼睛烫出洞来。
- 轴二 **听觉 ↔ 体感**：咔哒。每一次呼吸，都会让肺部如灼烧般疼痛。
- **禁止**颜色写成声音、时间写成触感这类跨两轴以上的混搭。

**气味三叠**（一句三重味道：嗅觉是第二通道的首选）：

> 公式：`[味1] + [味2] + [味3] + [侵入方向]`
>
> 空气里全是烤串的孜然味、劣质香水的脂粉味，还有人群身上那股子汗腥味。
>
> 那股属于成熟男性的、混合着金属、汗水与淡淡肥皂香的冷冽气息，如同无孔不入的迷药，肆无忌惮地钻进她的鼻腔和毛孔。

六组可调用的配方：**夜市** = 烤肉孜然 + 劣质香水脂粉 + 汗腥；**码头** = 水腥 + 劣质香料 + 麦酒酸；**小酒馆** = 烤肉香辛料 + 烈酒；**地下室 / 车库** = 霉味 + 铁锈；**雨后的巷子** = 湿土 + 垃圾发酵；**双层伪装** = 香水外壳 + 汗味内里（只在细嗅时露出第二层）。

### 7.9 落点：最后那一口气落在哪

7.1 的落点纪律（「最后必须有东西接着」）具体只有四型：

| 落点 | 例 |
|---|---|
| 人体感（最常见） | 混在吹拂的南风中让人的**鼻子稍微发痒**。 |
| 人物下一个动作 | 她看了看清晨的景色，**之后才转过身来，洗漱和更换衣服**。 |
| 声音 | 偶尔有风拂过屋檐下的铜风铎，**发出清凉的声音**。 |
| 时间推进 | 慢慢的，夜渐渐深了，**窗外的天空浮现些许星星，一闪一闪**。 |

### 7.10 形容词密度与通道上限

**书D 633 句实测**：一句环境平均只用 **0.98 个形容词**；**38.2% 的环境句一个形容词都没有**；形容词只占总字数的 **2%**。

**克制写法靠名词 + 动词撑画面**：

> 一只黄狗躺在石桌的阴影下，时不时蹬蹬腿，吐着热气。
> 左边是厨房，一墙相隔的地方是洗浴室，右边是卧室兼书房。

**浓艳写法只在三种场合出现**：① 异变 / 灾变 ② 盛典礼仪 ③ 主角情绪顶点。过场、赶路、日常房间一律淡描。

**通道上限**：默认只用眼睛，最多再开一个；第三通道只留给 60 字以上的大场面 / 情色身体化，且末尾必须落一个身体词或情绪词。这条与 7.1 的长度公式同源。

**环境专查**（写完搜一遍）：

1. 成段的景物铺排（连着三句以上都在写景）
2. 「静静伫立 / 静静矗立」类：真人写作改用「已经」「就那么」「一直」
3. 环境自带情绪形容词（「恐怖的森林」「美丽的湖泊」）：情绪由人物承担，不由森林承担
4. 一句开五个感官通道
5. 环境里夹主角评价（「他觉得这里很美」）
6. 空转的天气（「阳光明媚，微风和煦」，不带任何作用）
7. 连续两章同一个场景，各写一次全景

### 7.11 两条附注

- **别重复报时空**：章节标题若已经写了「某夜，某地」，环境句就不要再报时间地点，直接给那一秒的质感；标题不带时空信息时，环境句才兼职定位（用 7.3 / 7.4 的公式）。
- **人只当镜头**：视点锚定句里，人只能出现在**句首或句尾**，且必须带一个「看 / 走 / 听 / 闻」的感官动词，中间仍然是景物。
  - ✅ 光秃秃的枝丫在风里抖着，发出细碎的响声。
  - ❌ 他看到了光秃秃的枝丫在风里抖着。
