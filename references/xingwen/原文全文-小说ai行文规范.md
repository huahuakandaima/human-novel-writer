## 二、叙事总契约

### 2.1 三个位置

本规范采用的叙述方式：**全知的第三方叙述者（上帝视角），叙述层统一用第三人称——名字与「他 / 她」。**
要让这种写法不混乱，必须先把三个位置分清楚：

| 位置 | 是什么 | 设定 |
|---|---|---|
| **叙述者** | 讲故事的人，不属于任何角色 | 全知、有性格、会吐槽、会预知；**永远不以「我」自称** |
| **主角** | 故事的落点 | 叙述层用**名字 / 他 / 她**指称的中心对象；**主角不是读者** |
| **读者** | 旁听者 | 站在故事外，听叙述者讲主角的故事 |

> 核心概念叫**「视角契约」**：叙述者是那个说话的人，主角是那个被叙述的人，读者只是旁听。
> 读者不需要把自己当成主角，他们只是被邀请来看另一个人的人生。
> 所以主角可以拥有读者没有的经历、性别、能力——因为主角是一个完整的角色。

**主角是叙述的落点，不是叙述的眼睛。**
镜头挂在主角身上，但随时可以离开：主角有盲区、会想错、有些事根本不知道，叙述者却全都知道，这正是全知视角存在的理由。

### 2.2 人称规则表

上帝视角下**所有角色用同一套规则**——主角并不特殊，特殊的是「镜头挂在谁身上」：

| 场景 | 叙述层用什么 | 例子 |
|---|---|---|
| 主角在场、动作、外貌 | **名字 / 他 / 她** | 他推开那扇门，走廊的灯一盏接一盏亮起来。 |
| 主角的心理 | 直接进入内心，不必每句都用「他想」包一层 | 他忽然意识到，她说的「下次见」不是客套。 |
| 其他角色的动作 / 心理 | **名字 / 他 / 她**，同样可以进入其内心 | 他靠在窗边，指尖的烟明明灭灭，他其实一直在等她回头。 |
| 跳去别人的故事线 | **名字 / 他 / 她 / 有人**，镜头离开主角 | 城市的另一端，有人拨通了电话：「她不见了。」 |
| 叙述者本人 | **禁止「我」** | 用「后来他才知道」「说来可笑」这类话代替。 |

**两条硬规则**：

1. **叙述层禁止用「你」称呼主角**（台词、以及本规范对写作者的指示除外）。主角统一用名字 / 他 / 她。
2. **代词必须可消歧**：同一场景出现两个同性角色时，用名字或身份（「名字」「老板」）锚一下，
   不要让读者猜这个「他」是谁；**名字与代词轮换使用**。首次出现用名字，之后用代词。

> ⚠️ **姓名第一位，他 / 她居后。** 小说里角色的**姓名和称呼（名字、身份、头衔）是第一位的**，
> 「他 / 她」只是接力，先靠名字把人立住，代词才有得可指。
> 本规范里的文字示例为了通用，**只使用了「他」和「她」**；具体角色叫什么名字，**由用户自行决定**。

### 2.3 主语的使用纪律（避免疲劳）
主角的名字和「他 / 她」用多了，尤其是每句都拿它开头，一样会腻。三条纪律：

- **不要每句都以主角名字或「他」开头**。用时间、地点、物件、结果做句首。
  - ❌ 他推开门，看见了走廊尽头的她。他愣住了。他不知道该不该过去。
  - ✅ 门被推开，走廊尽头那个人就站在那里。灯光斜斜地打下来，心跳声变得格外清晰，他低下头，忘了自己要说什么。
- **让主角出现在句中、句尾**，轮换位置；动作连缀的句子能省主语就省（见 5.3）。
- **主语承担的职责要变化**：定位（他在哪）、回忆（他想起什么）、判断（他意识到什么）、决定（他选择什么）、被击中（他愣住）。

### 2.4 视角切换与跳转

世界允许**多线并行**：主角的事件结束后，镜头可以跳去其他地方，讲别人的互动和故事。但跳转必须让读者看得懂：

| 跳转类型 | 信号 | 例子 |
|---|---|---|
| 场景 / 时间跳转 | 独立成段的破折号 | 她走出咖啡馆，雨刚好停了。 / —— / 三天后，老宅的灯还亮着。 |
| 空间并行 | 与此同时 / 另一边 / 画面一转 / 另一头 | 与此同时，城市的另一端，有人把写着她名字的那页纸丢进碎纸机。 |
| 视角跳转 | 换行 + 明确主语 | 他按掉手机屏幕，沉默了很久。 |

**纪律**：

- 一场戏（对话 / 拉扯 / 冲突）内视角切换**不超过 2 次**。
- 跳去别人故事线时，**先交代「谁 + 在哪」**，不要让人猜。
- 切回主角这条线时，可以用一个动作或一个场景标记点自然接回来，不必解释。

### 2.5 叙述者可以做什么

这是上帝视角最大的优势：**叙述者是有存在感的**。叙述者可以：

1. **预知与回望**（言情利器）：
   > 那时候她还不知道，这个总在深夜给她发消息的男人，三个月后会替她挡下那颗子弹。此刻她只知道，屏幕又亮了：「睡了吗？」

2. **补充设定**（借「世界户口」句式，详见 6.4）：
   > 有些人在这个圈子里是被公开谈论的，官方叫他们「专家」，民间叫他们「疯子」，而她，两者都不算。

3. **评论命运**（片段末的意象对仗）：
   > 她抬头望天。 / 整栋楼的人都不约而同的抬头。 / 只有他一直在看她。

**但预知是重武器。** 它一旦高频使用就会迅速变成狗血，读者会开始预判而不是被击中。
- **一个片段最多用一次**，且只在情绪确实需要时才动用（悬念、反差、宿命感）。
- 日常推进的片段里不要用。
- 同一段故事里，第二次使用要有明显升级（从「他知道」变成「他早已知道」）。

## 三、铁律：动作与台词，不许用三五个字干打

> 第二节管「谁在说」，本节管「说得像不像人」。
> 它**压过后面所有关于节奏、短句、段长的技法**：第四节、第五节那些技法，都是在「已经像人」的前提下才谈得上的；一旦违反本节，节奏再好也是 AI 味。
> **但「写足」不等于「句句都写足」**：该写足的地方写足，该一句带过的地方就一句带过——详略怎么分，见 4.1。

### 3.1 病症：把一个活人写成了符号

AI 最大的破绽在这里：它爱把一个真人做的事，压缩成三四个字。看上去干净、克制、惜字如金，
实际上是把人写成了机器零件。**这些句子有一个共同点：除了「发生了什么」，什么都没有。**

| ❌ 干打（举例） | ✅ 应该怎么写（仅仅是示例） |
|---|---|
| 他没停。 | 他并没有想着要缓一缓，脚下的步子反倒比刚才更快了。 |
| 他停下。 | 门外传来的声音让他停下了脚步 / 他开始减速，慢慢停了下来。 |
| 她没说话。 | 她没有吭声，只是隔着那张桌子看着他，目光一直没有挪开。 |
| 她没回头。 | 她并没有回头，只是把脚步放慢了些，让他跟得从容一点。 |
| 他没细想。 | 他没有细想 / 他没怎么细想 |
| 他动了。 | 他到底还是动了，手比还脑子快，先一步替他抢来了答案。 |
| 他收住了。 | 他还是把后半句咽了回去。/ 他并没有继续加快速度，渐渐收力开始放缓。 |
| 他没有回答。 | 他没有立刻给她回答，只是把手插回裤袋，直直盯着她的眼睛。 |
| 她同意了。 | 她算是点了头，动作轻得谁都能看出来她很不情愿。 / 「行啊，我同意了。」/  |
| 他拒绝了。 | 他摇了摇头表示拒绝 / 他直接拒绝了她 / 「我不同意。」说完他一刻没停转身就走了。 |
| 两人沉默了。 | 两人都沉默了，谁都没有先开口。 |
| 她生气了。 | 她把杯子往桌上一顿，水都溅了出来，这次她是真的有些生气了 / 她冷着脸，一看就是生气了 |

**右边不一定要更长**：它们的最低标准只是「把话说完整」：谁在做什么、什么状态、什么态度，不再是电报。写到「脚下的步子反倒比刚才更快了」这种细度当然好，写到「她点了点头表示同意」只要不再像机器，也算数；当然，在一些表达上用人物的话来补充更好。
**只有「她点了头」这种光秃秃的动词是不行的**——但也不要把「补全」变成另一种公式，该短的人就让他短，短得有理由就行。**关键是别让句子只剩一个动词。**

### 3.2 为什么这是 AI 味的核心

- **短到极限的句子就像是节拍器。** 读起来不连贯、严重缺人味就是这么来的。
- **这种病会传染。** 一段里出现一次「他停住了」，整段的语感就往下掉一档。
- **对话里最容易暴露，但要先分诊**：这是叙述者偷懒，还是这个人物本来就惜字如金？——判据见 3.4。

### 3.3 补全手法：给每个动作补上「动作」以外的东西

写完一个动作，先问自己一句：**这句话除了「做了什么」，还少了什么？**
从下面几项里**至少补上一项，最好两项**；**最低限度也要做到「换个说法 / 明确化」**——
就是不能让它只剩一个光秃秃的动词（对照 3.1 表里的「她点了点头表示同意」，那种程度已经算数）：

| 补什么 | 怎么补 | 例子 |
|---|---|---|
| **修饰**（快慢 / 轻重 / 犹豫 / 含糊） | 给动词加副词，或把动作塞进一个定语里 | 她**轻轻地**摇了摇头，摇到一半又突然停住 |
| **状态**（身体 / 手边的东西此刻是什么样） | 动作发生时，手、袖口、杯子、烟头是什么样子 | 他把行李箱的拉杆又往下按了一格，指节压得发白 |
| **心理**（在想什么 / 怕什么 / 赌什么 / 想瞒住什么） | 叙述层可以直接进角色的内心，不必用「他想」包一层 | 他并不打算让她等太久，可话到嘴边，他还是决定说得更慢一点 |
| **程度 / 时长**（多久、几次、多急） | 把一个瞬间拉长，或者压一下 | 她隔了很久才回答，久到他以为她根本不会回答了 |
| **余波 / 结果**（动作之后留下了什么） | 让动作有落点、有代价、有痕迹 | 她急忙收住脚，可还是把他绊倒了 |
| **换个说法**（同义替换 / 反着写 / 换施动者 / 换施动时刻） | 不重复同一个动词 | ❌ 她不同意 → ✅ 她把头偏开不看他，视线落到窗外去了 |

**台词同理**：人说话会带语气词、重复、吞咽、反问、说到一半改口、临时换措辞：

> ❌ 「滚。」
> 她走了。
>
> ✅ 「滚。」
> 话从她牙缝里硬挤了出来，她已经受不了了。

**唯一不能一刀切的是台词**：它长还是短，由这个人物的**性格、处境、关系**决定，判断标准在下一小节。

### 3.4 台词：长还是短，由人物决定，不由句子决定

**台词的长度不是「标准」，是人物属性。** 它由三件事决定：

| 决定什么 | 影响什么 |
|---|---|
| **性格** | 有人天生话多，有人一辈子惜字如金。话少是他的**人设**，不是缺陷 |
| **处境** | 被震住、语塞、疲惫、垂死、被拿捏的时候，人本来就说不出长句 |
| **关系** | 亲疏、地位、戒备、试探，决定话里有多少余地、有多少刺 |

所以**不能一刀切地要求台词变长**。真正要禁的只有一种：**叙述者偷懒。**

> **一条判据就够了：一个角色可以全程惜字如金，但叙述层不能惜字如金。**
> 人物话少是设定，读者能感觉到这个人的性格；旁白话少是偷懒，读者只会觉得文本没人味。

#### 一、该短的台词：短得有理由

三种合法形态，每一种都必须自带「证据」：

| 形态 | 什么时候用 | 必须给的证据 | 例 |
|---|---|---|---|
| **人设型** | 这个角色本来就寡言 | **全段贯彻**他每一次开口都短；并且**周围必须有话多的人做对照**，反差才成立 | 他：「嗯。」／「不用。」<br>她：「你怎么才回来——都两个小时了，汤我都热了三回。」<br>他脱下厚重的外套挂在衣架上，蹲下身脱鞋，全程没有一句解释。<br>又是这样，她叹了口气。<br>「微波炉。」说完她就回卧室了。 |
| **语塞型** | 被震住、说不下去 | 生理表现（喉结、吞咽、停顿、呼吸）+ **叙述者把没说出口的那部分补出来** | 「你……」她张了张嘴，后半句到底没能说出口。 |
| **关系型** | 生分、对抗、试探 | 短句带刺；**改口和没说完的部分承担信息** | 「不用了。」她顿了顿，「……我一个人可以。」 |

> ⚠️ **人设型必须「独一份」。** 同一场戏里如果每个人都惜字如金，那就不是人设，是缺货。
> **一个短句角色 + 一个啰嗦角色**是写法；**三个短句角色**是偷懒。

#### 二、该长的台词：长得有内容

话多不等于水。长的地方必须有「东西」：追问、试探、绕、掩饰、词不达意、说给自己听。而且不一定非得一句话全部说完，你可以把一句拆成几个连续的段列在一起。

> 「你今天回来得怎么比平时晚了两个小时？」
>
> 「我不是要问你去了哪儿，我只是想说......」
>
> 「我下午给你熬的那锅汤热的我已经尝不出味了。」

这不是把句子拖长，是**把她没说出口的东西说出了形状**。

#### 三、兜底手法：短台词必须被「托住」

极短台词**可以有**（「嗯。」「……算了。」），但要被**一样东西托住**，三选一即可，不能一个都没有：
**一个动作**（「嗯。」他把手里的伞收了，伞骨在台阶上磕出一声）／
**一个神态**（「不用。」她眼睛落在别处，落了很久）／
**对方的动作反应**（「滚。」／他愣了两秒，转身把门带上，比来时轻）。

#### 四、三问判据

1. **这个人物少说话，读者能感觉到他的性格吗？** 能 → 合理简短。
2. **这段台词短，是因为这个人物此刻说不出 / 不想说，还是因为我懒得写？** 是「我懒得写」 → 干打，必须改。
3. **短台词说完之后，有没有人接、有没有反应、有没有余波？** 三样都没有 → 翻页太快了。

**短句怎么断行、什么时候允许 10 字以内，见 5.2。**

## 四、行文逻辑：自下而上四层

不管写什么片段，永远**自下而上**写：

```
第4层  节奏层：段落怎么切、句长怎么配、何时单句成段
第3层  情绪层：这段服务什么情绪（暧昧 / 紧张 / 好笑 / 心疼）
第2层  视角层：镜头在主角身上，还是跳去了别人那里
第1层  事件层：谁做了什么，导致什么
```

**先想事件，再定视角，再定情绪，最后调节奏。**
绝大多数「AI 味」都是倒着写出来的，即先堆词藻，再补事件。

**反公式化节奏**：不要每次都是「场景交代 → 对话冲突 → 结尾钩子」。
一个片段该在哪里停就在哪里停：可以停在一个动作、一个画面、一句没说出口的话上。
**连贯性 > 完整性**：宁可为上一段情绪的延续多写两句，也不要为了「一段完整的情节」生硬收尾。

> ⚠️ **节奏层的硬约束（见第三节）**：以上说的「停在一个动作上」，是指停在**一个写足了动作的段落**上，
> 不是停在「他停住了。」这种三个字的干打上。**短，是断行的结果，不是省字的理由。**

### 4.1 详略主次：不是每句话都值得写足、修饰、打比方

> 第三节治「全都太短」，本节治「全都写满」。**两条同向，合起来才完整：**
> **该写足的地方写足，该一句带过的地方就一句带过。**
> **详略由「主次」决定，不由「句子」决定**——不是每句话都要修饰一下，也不是每个细节都值得写细。

**主次三问**（写完一段，先分主次，再改字）：

| 问 | 主 | 次 |
|---|---|---|
| 这句在推动什么 | 主线事件、关系变化、情绪拐点 | 只是在填时间、填空间 |
| 读者需要记住它吗 | 需要 | 不需要 |
| 它在段里的位置 | 爆点、转折、关键动作 | 过场、过渡、读者早就知道的事 |

**详略配比**：

| 位置 | 给多少笔墨 | 怎么写 |
|---|---|---|
| **主**：本段的情绪爆点 / 转折 / 关键动作 | 写足 | 修饰、状态、心理、程度、余波至少补两项（见 3.3），长一点没关系 |
| **中**：主线需要的必要信息 | 写清楚 | 写完整的句子，但不加装饰 |
| **次**：过场（走路、拿东西、一句「走吧」）、重复信息、读者早知道的事 | 一句带过，或干脆不写 | 「他收拾好东西，出了门。」这种程度就够，不要再拆成五句 |

**主次的手腕里，「不写」也算一种。** 该跳的地方直接跳过去，读者不会觉得少了什么；什么都写，读者反而什么都记不住。

**四条禁令**：

1. **不许句句都修饰一下。** 修饰是重音，句句都加就等于没有重音。一段里只在本段的重音处修饰，其余用白描。
   > ❌ 他缓缓地、轻轻地推开那扇沉重的、有些掉漆的木门，小心翼翼地往里探了探头。
   > ✅ 他推开门，往里探了探头。门轴没响，他反倒站住了。
2. **不许什么都写得很细。** 详写是一种注意力分配；全都详写＝没有重点，读者会累，读到真正的爆点反而没感觉。
   判据：**这段如果只留三句话，该留哪三句？** 留下来的才是主。
3. **不许动不动就打比方。** 比喻是重武器，一段最多 1 个（见 5.9）；凡是不值得写足的地方，也不配给它一个比喻。
   > ❌ 他笑了，像春风拂过山岗；他皱眉，像乌云压住城头；他叹气，像秋叶落尽。
   > ✅ 他笑了笑，转头去看窗外——这一处不值得用比喻。
4. **不许流水账。** 见下表。

**流水账的三种长相**（流水账 = 有顺序，没主次）：

| 长相 | 什么样子 | 改法 |
|---|---|---|
| **时间流水账** | 起床、洗漱、下楼、买早饭、挤地铁、到公司……一件事一件事按钟点记 | 只留与情绪 / 冲突有关的动作，其余压成一句，或直接跳到下一个有戏的地方 |
| **动作流水账** | 他推开门，走进去，坐下，拿起杯子，喝了一口，又放下 | 动作链本身没错（见 5.10①），错的是**链上每个动作一样重**：链条要服务一个爆点，落点落在主上 |
| **对话流水账** | 一来一回全是信息，像会议记录 | 留废话、留打断、留答非所问（见 5.13） |

**一条判定方法**：给这段的每一句在心里标一个「主 / 次」。
- 全是「主」→ 说明你没分主次，回头砍。
- 连着三句以上都是「次」→ 压成一句。
- 只有一两处「主」、其余都是「中 / 次」→ 这才是正常的段落。

> ⚠️ **本节不是给第三节开后门。** 「一句带过」指的是**过场**，不是「他没停。」这种干打。
> 干打是把一个该写足的动作写没了；流水账是把一堆不该写足的事写满了。**两个都要改。**
> 详略也不是按字数平均分的：一段里可以有 150 字的详写，也可以有 5 个字的带过，**差别本身就是重点**。

## 五、句子层技术：怎么让句子活起来

### 5.1 破折号插入语（叙述者吐槽和后续解释）

**吐槽公式：高调 / 正经 / 华丽地说完前半句 → 破折号 → 立刻补一句日常化、吐槽、或补充。**
**后续解释公式：前半句 → 破折号 → 解释和说明**

> 她说她只是顺路送他回来——凌晨两点，她绕了半个城。
>
> 他一边嘲笑，一边向后退去——有人用浩瀚的魔力屏蔽了他对面前老人的感知。
>
> 精致的面容仿佛被优秀的匠人雕刻过般——不，没有匠人可以雕刻出如此完美的作品。
>
> 少女的再度开口让评鉴师停止鉴赏，并附上评语——除了不是哑巴都是优点。
>
> 他那套拳法据说是祖传的——他爷也这么打，打了一辈子没赢过。

- 破折号前用正经词，破折号后用日常词，**落差就是人味**。
- **注意**：叙述者式的吐槽所用的破折号，不要每段都用，破折号**千万不要滥用**，每2000字里最多最多两个。而且吐槽要讲地方，不是什么地方都要塞进去，有的故事严肃，有的故事戏剧，要分场合和观感，就算适合也不要各个段里都出现一次，会导致疲劳。吐槽有时可以直接用「......」代替，正好解决破折号太多的问题，看着也更美观。

### 5.2 单句成段与短语成段（节奏的核心武器）

网文是竖着排的，**一个意思一行**。多数段落在一两句之间断掉。

> ⚠️ **但「一行」不等于「三个字」。** 断行是情节展示的结果，**绝不是把句子砍到极限的理由**。
> 「他没停。」「她没说话。」「他动了。」再怎么断行，也是干打。这实际上是一种「弱保软」，有的地方其实是可以用的，但ai用的方式对阅读和观感影不影响，很难界定，所以还是尽量少用。

**三条规矩**：

1. **短语段必须承接，也包括收尾的那个。** 前面得有一句完整的、实写的句子垫着，短段才是顿；
   一上来全是短语、或者用短语收尾，整段就全是干打（后者叫「干打收尾」，AI 味最重的一种）。
2. **一个场景里，纯短语段不超过 2~3 个**，而且不连着超过 3 个。
3. **交代动作、行为的句子，不得单独放进 10 字以内的段落里。**
   （台词是例外：极短台词只要符合 3.4 的三种合法形态、并且被托住，就允许独占一段。）

**10 字以内只允许这五种**（它们属于修辞装置，不属于干打）：

| 允许 | 例子 | 为什么行 |
|---|---|---|
| 时间 / 数字（计时递进） | 一秒。 / 两秒。 / 三秒。 | 这是节拍器；前提是前面有实写的时间锚点 |
| 拟声词 | 嗡—— | 声音本身 |
| 否定 / 反问式的顿 | 不是巧合。 / 不是直觉。 | 承接上一句的排比，是锤击，不是省略 |
| 意象对仗（收尾三连） | 她抬头望天。 / 整栋楼的人都在抬头望天。 / 只有他，在看她。 | 这是修辞装置，不是叙事 |
| 标签清单式短句 | 赤红的长发，红色的瞳，红色的长袍。 | 这是标签；紧跟其后**必须**补一个完整的行为句 |

> **长短段都是倾向，不是铁律。段落该长的时候就得长。**
>
> 段落长度是**叙述呼吸的结果**，不是用来凑节奏的。判断标准只有一个：
> **这一段读起来顺，就留着；读起来憋气，才拆。**
>
> | 什么时候该用长段 | 什么时候该用短段 |
> |---|---|
> | 需要连贯铺陈的质感：动作链、环境、感官、情绪的流动 | 需要停顿、定音、制造落差 |
> | 一个完整动作的分解（不许中途切断） | 情绪刚转弯的那一瞬 |
> | 详尽描写：肉体、衣物、气味、触感需要连成一片才成立 | 逼近感（计数递减） |
> | 高潮中持续推进的动作与感官交织 | 高潮落定后的定格 |
>
> **详尽描写天然需要长段。** 一段详尽的触感描写如果被切成三段，气就断了，读者要重新定位，画面反而散掉。
> 这时候宁可让它长到 150 字，也不要为了「节奏」去拆。
>
> **判断句式的流畅性**：读一遍，凡是读到一半需要「喘一下才知道说到哪了」的地方，就该拆。
> 凡是读完一口气到底、还想再读一遍的地方，就该留着。
>
> **详略也不平均分配**：该写足的地方写足，该一句带过的地方就一句带过（见 4.1）。

**情绪刚变化的瞬间，用短段钉死**，但**前面必须先有一句实写的铺垫**，钉下去的才是「顿」，不是「省」：
> 她的手指还停在门框上，人却像是被谁从背后按住了，一动也没动。
>
> 三个月前，也有人对她说过一模一样的话。
>
> 一字不差。

> 男孩沮丧地低下头。
>
> 第二十次尝试失败了。

**逼近感用递进短句**（数字本身递减，读者自动感到距离在缩）。
注意：这是**计时刻拍**这一种专门场合，前面必须有一句实写的时间锚点；
它**不能**拿来代替动作描写：
> 他抬手看表，秒针刚跳过那一格。
>
> 一秒。
>
> 两秒。
>
> 三秒。

递进落到结果时，用单独一段收，**但落点句要写足，不能只写「她脸红了」**：
> 一秒。
>
> 两秒。
>
> 她的耳朵，以肉眼可见的速度红了，一路烧到脖子根，连说话都结巴了半拍。

**拟声词独立成段**：
> 嗡——
>
> 一辆汽车擦着他的头发飞了过去，气流直接把他的脸吹的有些变形。
>
> 紧接着，耳边就传来巨大的爆炸声。

**拟声词之后必须紧跟一个动作结果**：

> 砰——！
>
> 「呜！」
>
> 他发出一声短促的悲鸣，整个人条件反射地抱头蹲防。

### 5.3 主语省略 + 动作短语连缀

中文网文大量省略主语，用动词短语 / 名词短语做主语，制造电影分镜感：

> 门被推开一条缝，风裹着雨味扑了进来。指尖传来微微的灼烫——是那张照片，被她攥得已经皱了一角。

**公式：动作，+ 结果，+ 再一个动作。** 全句不出现主语也成立。
书A 里甚至有「门，被拉开了一条小缝」，连门都能当主语。

> ⚠️ **边界**：短语成段是**镜头感**，不是**省略术**。
> 一段里只许用一两次，其余必须是完整句；连着三个短语段，读者只会觉得卡带（见 5.2）。
> 这里的「推开门」可以短，但**带结果、带余波**，只写一个动词就收，是干打。

### 5.4 长定语不带「的」套娃

连续 3~6 个定语**不带「的」**，靠动词副词自足，最后落回中心词。适合吐槽、夸张、角色口头禅：

> 「你就是那个传说中、档案上写满红章、被追了三年却依旧活蹦乱跳的『前·最强』？」
>
> 「您就是那个传说中至高无上、讲话神神秘秘却又毫无实力的冥界至尊无敌飞天乌鸦？」

### 5.5 四字短语插入（把成语当逗号用）

在长句中间塞一个四字 / 六字短语，给白描瞬间上色：

> 她走在鹅卵石小路上，身姿轻盈而有力，玉手托腮，心事重重，她在想他今晚会不会来。

### 5.6 递进式短语成段（情绪爆发 / 高潮）

把一句话拆成 3~5 个逐段短句，形成锤击感。
**前提：第一个必须是一句实写的长句**，把读者情绪先架起来，后面几个短段才有落下来的重量：

> 她终于明白，他为什么总能在她出事之前出现。
>
> 不是巧合。
>
> 不是直觉。
>
> 是他一直在盯着她。

> 说白了就那月亮李白看了都摇头。
>
> 简而言之，这里就是个鸟不拉屎的地方。
>
> 不对，这儿连正常的鸟都没有。

> 他不回消息，说明他没看见。
>
> 没看见，说明手机还在包里。
>
> 手机还在包里，说明他今天根本没想起过这件事。亦或是，他想起来了，只是不想回。

### 5.7 对话标签：能省则省，缀一个动作 / 神态

- 约 **1/3 的对话完全不用标签**（裸对白）。
- 六成以上的对白后面**缀一个动作或神态补语**，不要只写「他说」。

> 「我不喜欢你。」他垂下眼，把指尖的烟掐灭了，动作很轻，像是在掐灭什么不该有的念头。
>
> 「那你为什么还跟着我？」
>
> 他没有立刻回答，只是把手插回裤袋，指节在布料上蹭了两下。路灯下，她的影子和他只隔了一掌的距离——这个距离，是他说漏的嘴。

> ⚠️ **不许写「他没回答。」「她没说话。」就翻页。**
> 「不说话」「不回答」本身也是一个人做的事，它有姿态、有原因、有余波，写出来，才叫人在场（见第三节）。
> ⚠️ 注意这是**叙述层**的要求。**台词本身可以短**，那是人物属性问题，见 3.4。

**后置标签里可以带主观评价**（叙述者的态度渗进去）：
> 他很认真地点了点头，认真得有些好笑。

**四种固定词序**：X + 动作 + 说道 / 道 ｜ 动作前置，说话在后 ｜ 说话中插动作（动作夹在两段引号之间）｜ 全部省略，只留动作。

**区分声线**：不靠「XX 说道」重复，靠人物 A 的语言特征（口头禅 / 句长 / 语气词） + 人物 B 的固定行为反应（不接话，而是做另一个动作）。

### 5.8 标点纪律

| 标点 | 怎么用 | 示例 |
|---|---|---|
| 逗号 vs 顿号 | **默认用逗号连缀**（叙述层是书面感的全知叙述者）。顿号只允许出现在「他 / 她的原话」和快速罗列里 | 她五官清冷，气质疏离（叙述层，逗号）/「眉目清冷、心思难测」（台词，顿号） |
| 问号 vs 感叹号 | **吐槽、心理戏用问号**；爆发、告白、高光才用感叹号 | 「这也能叫运气？」比「这也能叫运气！」更有调侃味 |
| 省略号 | 犹豫、话没说完、留白；**吐槽里可以直接用六个点「......」**（比「……」更轻、更滑稽，见 5.1） | 正剧：「我……」她张了张嘴，那半句话到底没能说出口。／吐槽：「你昨天挺忙啊......」 |
| 破折号 | 叙述者插话、声音拖长、话被掐断、说明解释 | 他推开门，门后站着一个不该在这里的人。 |

**情绪克制是高级感**：感叹号用多了就廉价了。书A 全书 31 万字只用 284 个感叹号、1456 个问号，情绪依然饱满。**疑问句是感叹句的五倍**，这是叙述者吐槽能成立的技术基础。

### 5.9 比喻纪律

- **喻体要落在读者不用想就懂的东西上**，具体落在哪个圈层**由题材决定**：都市 / 校园 / 日常向 → 游戏、外卖、考试、猫、泡面；奇幻 / 异能 / 古代向 → 山川、兵刃、牲畜、市集、香火、酒食。**唯一越界的是「生僻」**：不管什么题材，读者要想一下才明白的喻体 = AI 味。
  - ❌ 她的笑容如同春日晨曦中绽放的第一朵玫瑰，纯净而圣洁。
  - ✅ 她笑起来的时候，像外卖提前十分钟送达——他明知道没什么大不了，还是开心了一下。
- **单段最多 1 个比喻**；恋爱场景 3~5 段才放 1 个，其余用白描。**比喻只留给本段真正有分量的那一处，见 4.1。**
- 每个角色全书比喻不超过 5 个，且要「专属化」（她像猫，就一直像猫）。

### 5.10 长句的五种合法结构

**详尽描写就该用长段**（见 5.2），这里补上另一半：一段能撑住的长句，是由若干个**带连接关系的模块**串起来的，不是靠形容词堆出来的。

**① 动作链**（时间顺序，最常用）

> 她挺起傲人的胸膛，浴巾被撑得发出一声危险的布料摩擦声，踩着赤裸的玉足，大步流星地走向门口。

四个动作用逗号串起来，动词一路推进，读者能「看见」整个过程。

**② 感官叠加**（同一瞬间的多个感受）

> 巨大的力量顺势往回一收，她娇软的身躯，直接严丝合缝地撞进了一个滚烫、结实、散发着浓烈男性气息的宽广胸膛里！

**③ 因果链**（一个接一个的「所以」）

> 他们本不该有任何除了战争以外的交集。但这一切都真真切切地发生了，就像是那晚的月亮依旧如往日明媚——这是不争的事实。

**④ 总—分—总**（先给整体印象，再拆开，最后收回）

> 他就像是一个再平凡不过的长辈，正用和蔼慈祥的目光注视着眼前的晚辈们。仿佛前天那场惊心动魄、斩杀那头怪物的激战与他毫无关系，此刻站在这里的仅仅只是一个普普通通的老者罢了。

**⑤ 长定语 + 破折号补丁（见 5.1、5.4）**

### 5.11 长句崩坏的四个症状

| 症状 | 表现 | 修法 |
|---|---|---|
| **连接词断链** | 三个以上逗号分句之间没有逻辑词 | 补「然后 / 但 / 所以 / 等到」 |
| **形容词代替动作** | 「美丽的、温柔的、坚定的目光」 | 换成他做了什么 |
| **指代不清** | 长句里出现两个「他」 | 第二次出现改用「那个人」或具体部位 |
| **没有落点** | 一句话写完不知道停在哪 | 末尾加一个具体动作或物件 |

### 5.12 长段的分寸（两条硬指标）

- **叙事推进**：一个场景一段，不要超过 150 字。（详尽描写不受这条约束，见 5.2。）
- **超过 200 字还在加形容词**：停下，回到 5.10 重新挑一个结构。

判断方法：**把长段的最后一句单独读一遍。** 如果它不能独立成立、也不能自然接下一段，说明这段散了。

### 5.13 对白的人味：六个病征与六条规则

AI 写出来的对白，问题从来不是「不通顺」，它非常通顺。问题是**太通顺了**。

#### 一、六个病征

| # | 病征 | AI 的样子 | 人的样子 |
|---|---|---|---|
| 1 | **每句都在传递信息** | 每句台词都推进剧情 | 有人会答非所问、重复、跑题 |
| 2 | **从不打断** | A 说完 B 接，A 接 B | B 会打断、会插嘴、会同时说 |
| 3 | **句句完整** | 「我不喜欢你，因为你选择了别人。」 | 「你……算了。」 |
| 4 | **没有语气词** | 「我知道了。」「好的。」「嗯。」都写成完整句 | 「知道了。」「嗯。」「啊？」 |
| 5 | **没有自我修正** | 说出口就是最终版 | 说到一半改口：「我以为你……算了，你没说过。」 |
| 6 | **没有废话** | 台词里没有「嗯」「对」「哦」「那个」 | 真实对话里这些占三到五成 |

#### 二、六条可执行规则

**规则一：每五句对白里，至少有一句不是在回答问题。**

> 「你昨天去哪了？」
>
> 「公司。」
>
> 「哪个公司？」
>
> 「你昨天不是已经查过了吗。」
>
> 「……哦。」

**规则二：允许沉默。沉默也是对白的一部分。**
一整场戏一句台词都没有，是可以的；但沉默要写成一个动作，不能只写「他没回答。」（见第三节）：

> 他没有立刻回答，只是把手里的杯子转了小半圈。
>
> 楼下的车开走了，灯灭了一盏。

> ⚠️ **规则三、四承接 3.3 的既有结论**，这里只补它们在对白现场的具体用法，不重讲原理。

**规则三：结巴 = 心理防线在崩。** 人味痕迹的总纲见 3.3；对白现场最省事的一招是**用省略号标出卡住的位置**，放在哪，就是卡在哪。

> 「我、我不是那个意思……」
>
> 「你别这样。」
>
> 「你、你冷静一点……」

**规则四：重复是真实的。** 人紧张时会重复自己刚说过的话，而且**第二次通常比第一次更短、更急**。

> 「别走。」
>
> 「你别走。」
>
> 「……我知道。」

**规则五：标签用动作，不要用「说」。**

> ❌ 他愤怒地说：「你怎么会在这里。」
>
> ✅ 他把杯子放下，放得很轻：「你怎么会在这里。」

**规则六：给每个角色一个「不接话」的方式。**
这是区分声线最有效的手段，不是每个人都会回嘴：

> 「你装得好假啊。」他察觉到她的情绪。
>
> 她选择性失聪。
>
> 她选择性失明。
>
> 她选择性失……

（这三行是**叙述者吐槽式的修辞装置**，不算 5.2 禁止的「动作干打」，干打是叙述者偷懒，这里是叙述者在开玩笑。）

不接话、答非所问、做一个不相干的动作，**这比任何口头禅都更能认人**。

#### 三、自我检测

写完一段对话，问自己三个问题：

1. 把所有台词抽出来**只读台词**，能不能分辨出谁在说话？不能 → 声线没立住。
2. 台词里有没有一句是废话？没有 → 太干净了，加一句。
3. 去掉所有「说道 / 道」，换成动作标签，信息量有没有变？没变 → 标签是废的。

## 六、内容层技术：写什么才能打动人

### 6.1 用身体反应代替情绪词

**永远不写「他很紧张」「她很难过」，写身体在做什么。**
**也不要用「她没动」「他没理她」这种三五个字的干打顶替，身体反应要写全，才算写完（见第三节）。**

> ❌ 她非常紧张。
> ✅ 她的指尖掐进掌心，指节用力的有些发白，这才意识到自己一直屏着呼吸。

> ❌ 她愣住了，心里很乱。
> ✅ 她的勺子停在半空，奶油沿着杯沿慢慢化开，滴在桌面上也没人去擦，她就这么举着，像是忘了自己手里还拿着东西。

**同一个「很紧张 / 很慌 / 很震惊」，换一个身体动作**：

> ✅ 一滴冷汗顺着她的额头缓缓滑落。

> ✅ 慌乱之下，她下意识地用双手捂住胸前那条摇摇欲坠的浴巾。

> ✅ 她颤抖着伸出手，摸了摸自己的脸颊，皮肤细腻光滑，手指修长白皙，根本不是以前那双敲键盘敲出茧子的糙手！

> ✅ 她猝不及防，惊呼一声，整个人失去平衡向后倒去。

**言情专用（脸红递进）**：从脸到脖子到耳根到锁骨，一段一段写，只写红到哪里，不写「她很害羞」：
> 唇齿相接的一瞬间，她的脖颈以肉眼可见的速度变红。
> 那抹红从耳根蔓延到整个脖颈，甚至连锁骨都染上一层粉。

**荒诞类比代替生理描写**（降低油腻感）：
> 如果此刻她的脑袋上可以加一个排气口，那么恐怕在瞬间便会被蒸汽吞没。

**用物件代替情绪（最高级的一招，整段零情绪词）**：
> 指尖传来灼热感。他低头看，那截烟快烧到尽头了，烟灰积了长长一截，随着手指的抖动掉在袖口上，他也没有去掸。
> 他抬起头，那个人已经不在了。周围照旧人来人往，喧闹得像是什么都没发生过，只有他站的地方空出一块刚好一个人的形状。

### 6.2 用具体动作代替程度副词

「极其 / 无比 / 十分 / 绝对 / 简直」是网文程度副词通胀的重灾区。**用动作代替形容词**：

> ❌ 他非常非常生气。
> ✅ 他手里的纸杯被捏变了形，滚烫的咖啡顺着指缝滴在地板上，他像感觉不到一样，只是盯着她。

**同一个「很生气 / 很伤心」，换一个动作**：

> ✅ 这魔王的眼睛还在不由自主地往泡面桶上瞟，甚至还悄悄咽了下口水。

> ✅ 他早已哭得稀里哗啦，委屈巴巴地坐在地上抱着膝盖，眼神中闪过一丝怨毒。

**夸张的正解是「换算」而不是「形容词」**：不说很强，说「一秒半内把整层楼的灯压灭」；不说很美，说「她走过来的时候，谈话声低了两度」。

### 6.3 心理描写 = 预期违背

心理描写的功能不是抒情，是**制造「预期违背」**：角色建立预期 → 现实打破预期 → 落差产生笑点 / 爽点 / 心疼。

**自我拆台式心理（书A 招牌）**：破折号在句内自我更正式，笑点靠这个落差：
> 他的实力当然够看——还是够看的，差的那一点点，他自己心里没数吗？
>
> 不过就像是银行百亿资金被冻结后无家可归的人遇上了一个千万富翁。

**优先用破折号同行完成**。拆成分行短句也能表达，但语气会散掉，那股「刚说完就自己拆台」的劲儿就没了：
> ❌ 他的实力当然够看。
> ……够看的。
> 差一点点。

**反差句式**：「坚定的……迷茫」「自信的……心虚」：

> 他的眼神里充满坚定的……迷茫。
>
> 怎么干饭技能消失了？
>
> 尽管这和前世的「我是秦始皇，打钱」有点类似，不过不重要，只要留在她身边就行。

**褒贬对撞是反差笑点最省力的句式**：
> 这自然不会是什么好的预感。
> 这绝不是个好消息。
>
> 这个在外雷厉风行的贵族中年好像在此刻失去了一切骄傲的资本，成为了一个只是对女儿怪病无能为力的父亲。

### 6.4 设定投放：寄生在冲突 / 对话 / 吐槽里，绝不集中讲解

**世界户口句式**（投放世界观的最佳模板，三句）：
> 一个 X，但是 Y 的 Z。 / 这是其他人对它的看法。 / 至于为什么会出现 Y，这是未解之谜。

**设定三分法**：设定切成三块，每块之间插一句对白 / 动作打断。**一个设定只准完整讲一次**，后续只准引用代号。

> 门外那位小姐，脾气不算好，但从不背后议论人，这是全校都知道的。
> 那她今天为什么站在他身后？
> ……他还没意识到问题严重。

「城是守不住的，它并不是我们真正的敌人。」他表情严肃了起来，「我和她从未想过能够从敌人手中保下全城，此战胜负从开始就已经分晓。」

「敌人不是那只怪物吗？」莱茵大喊道，又意识到不妥，压低声音，「凭您的实力，解决它不是很轻松的事情吗？」

### 6.5 人物出场：外貌清单 + 一个爆点

不写完整容貌，列三四个特征 + 一个记忆点，然后自己吐槽标签：

> 他穿着一件洗得发白的黑卫衣，头发乱得像刚经历了一场爆炸——实际上也确实经历过。
> 这条街上没人知道他叫什么，只知道他叫「白噪音」。

**声音先到，人后到**（书A 几乎所有出场都这样，287 处）：
> 「就是你？」一道清冽的男声从背后响起。她回头，才看见楼梯口站着一个人。
>
> 「早上好。」一个青涩的声音响起，一个身着黑色正装的少年摘下贝雷帽，向她挥手示意。
>
> 「小姐，该吃早饭了。」一道温和的女性嗓音响起在门后。
>
> 「两个幼稚鬼。」一道女声响起，不过不是她。

### 6.6 让读者记住一个角色：记忆点系统

每个主要角色至少配置 3 样：
- **专属颜色 / 身体部位**（血红的眼瞳、银白的长发）
- **专属口头禅 / 语气词**（「呵呵」「不是吧」）
- **专属招牌动作**（抬头望天、摸下巴、捏眉心）

高级玩法：让多个角色对同一个人说同一句话，形成全书彩蛋。比如四个人都对他说过「你在想一些不好的东西」。

**出场模板**：先给标签，再自己拆标签。
> 赤红的长发，红色的瞳，红色的长袍。 / 这是个红人……红姑娘。

⚠️ 标签清单可以短，但**紧跟其后必须补一个完整的行为句**，光丢一串标签就翻页，是 AI 味。

### 6.7 开篇段：第一句怎么开

开篇是唯一一段读者会用「AI 味」标准来审判你的地方，它决定读者留不留下来。

**六种安全写法**：

1. **直接从一个具体动作切入**（最稳）：
   > 「嗯……嗯？」随着一声慵懒的呢喃，意识如同潮水般回归。他猛地从沉睡中惊醒，却发现自己正躺在一块巨大而温润的白玉祭坛上。
2. **从一个反常细节切入**：
   > 他没想到少女这么有实力，妥妥的小说大女主模板。
3. **从时间地点切入**（书A 常用）：
   > 三天后，学院门口。
4. **从对话切入**：
   > 「小晴，今早领导和你说了什么啊？」
5. **从叙述者的元评论切入**（上帝视角最擅长这个）：
   > 她并不在意这些，她甚至连她妈都不在意。

**❌ 不要用的开篇**：

> 夜色如墨，月光如水，城市的灯火在夜色中明明灭灭。

这是 AI 开篇的标准起手样式，四本原书里一次都没出现。

**三行原则**：前三行内必须交代 **谁 / 在哪 / 正在做什么**。三者不必齐全，但至少要给两个。读者读三行还进入不了状况，就会走。

### 6.8 场景切换：切换之后的第一句必须自足

三种切换信号见 2.4，这里补一条最容易被忽略的纪律：

**切换之后的第一句必须自足**，不依赖上一段的信息，读者不看上文也读得懂。

>
> 三天后，老宅的灯还亮着。

而不是：

>
> 他还是没走。

## 七、环境描写：怎么写、怎么架构、怎么融入

> ⚠️ **取材一律跟着用户设定的世界观走，本节公式只是骨架。**
> 公式里的方括号等只规定**结构顺序**，里面填什么，一律用**用户设定里的名词与世界观**：现实都市就写楼栋、街道、电梯、便利店、地铁、雨后的柏油路等；异世界就写那个世界的建筑、物产、天气与规则；古代、星际、末世同理。
> 本节引文示例为演示结构，混用了现实都市与奇幻取材：**学习结构，不要照抄名词**。

### 7.1 环境描写必须「有用」（基础纪律）

写景只干四件事，**写不出功能就删掉**：

1. 交代可利用的空间 / 规则
2. 承担情绪（推开出租屋的门，屋里黑漆一片，只有冰箱在响）
3. 暗示危险等级（天空阴沉，反常的黑色飞雪从天而降）
4. 制造人物关系（环境成为情感容器）

**把景物写活**：景物 + 喻体 + 喻体的动作。

>华丽的吊灯沉睡着，灯下红木长桌伫立在会客厅的中心，门前倚着一个晒太阳的……镜子。
>
> 唯有这淤泥中的古老宝石还散发着微弱的荧光，宛如呼吸般，以一种极为缓慢的速率明暗变化。

**感官优先级**：视觉 > 听觉 > 嗅觉 > 触觉 > 味觉。写景占篇幅 8%~12%，是配角。

**例外**：如果某个感官对角色是「失而复得」的，它值得写重。

**两条硬纪律**：

1. **独立成段，绝不夹在对白中间。**「对白 → 环境 → 对白」出现 0 次。
2. **主语是景物，不是人。** 九成以上的环境句以景物开头；用人称只做「视点锚定」，且人必须在句首或句尾。

**长度 = 感官通道数 × 15~20 字**：1 通道 15~30 字（转场），2 通道 30~60 字（主力），3 通道 60~90 字，且末尾必须落一个身体词或情绪词。

**感官配比**：视觉独占五成，其余零星补位；要加第二个通道时，优先加**嗅觉或温度**。

**喻体纪律**：只能取自主角「见过、摸过、吃过」的物质层（水、食物、常见兽、随身武器、日用器物），**不用抽象概念**（不写「时间如潮」「悲伤如影」）。

**拟人只给动作，不给情绪**：沉睡、吞噬、拖入、握碎可以，「孤独的灯塔」不行。

**落点纪律**：环境句最后必须有东西接着——人物的一个动作、一个声音、一种感受。接不上就重写。

### 7.2 篇幅与架构：写多长、写多密、怎么成组

**单位是「一句」，不是「一段」。** 连续环境句的「块」里，90%~97% 只有 1 句。

**密度是配角。** 独立环境句实测占全部句子 0.2%~1.6%，**每章 0.5~1 句**（场景切换那一章可以给 2 句）。

> ⚠️ **两个口径别混算**：7.1 里「写景占篇幅 8%~12%」算的是**字符篇幅**（含顺手捎在动作里的环境词）；这里算的是**独立成段的环境句条数**。写作时按条数执行即可，不必去凑篇幅百分比。

**「一句」是下限，常态是「两句一组」**：**54.6% 的环境句后面紧跟着另一句环境**；而「连着三句以上都在写景」在样本中出现 **0 次**。

成组只有一条结构，背下来就够用：

> **第一句静，给尺度与色调；第二句动，给一个能摸到的东西，或一个变化。**
> **一块（两句）里只给一个变化：声 / 光 / 味 / 人，四选一。**
>
> 四周是一座座燃烧的火盆，将广场内照得毫无阴影。
>
> 而在会场周围，是一层层看不到尽头的人，宛如海洋一般，那一双双各色的眼瞳倒映着火光。

**战斗 / 异变专用的五种推进式**（仍是一块两句，只是第二句在「推进」）：

| 式 | 例 |
|---|---|
| 数量级潮水推进 | 数不清的黑影从岩石缝隙、地底洞穴中钻了出来，如同黑色的潮水般涌向车队！ |
| 声音推进 / 声音缺席 | 空气中只有死一般的寂静，仿佛连风都停止了流动。 |
| 光线推进 / 吞噬 / 切割 | 原本明亮的灯光被无尽的黑暗吞噬。 |
| 温度推进 | 周围的空气被烧得噼啪作响，甚至连坚硬的黑曜石地板都开始呈现出融化的液态！<br>**都市版**：柏油路面被晒得发软，鞋底踩下去会留下一个浅浅的印子。 |
| 「突然」式局部突变 | 周围原本平静的雪地，突然像是沸腾的水面般，剧烈翻滚起来。 |

### 7.3 起笔：六种开头

| 起笔 | 频率 | 公式 | 例 |
|---|---|---|---|
| 处所方位起笔 | ~13% | `[处所] + [方位/结构] + [状态]` | 房间的楼道不同于刚才的卧室，有着一股阴凉的气息。 |
| 人物动作带出（视点锚定） | 7.1% | `[人物] + [站/坐/走] + [视线落到的景]` | 她此刻在旅馆的二楼，坐在敞开的窗户旁，看着远处的市集。 |
| 天气天象起笔 | 5.1% | `[天色] + [一个突然的天气动作] + [来源]` | 灰色昏暗的天空爆闪一次，然后隐约的雷声从遥远的天际传来。 |
| 时间词起笔 | 3.3% | `[时段] + [空间] + [残留的光/温度]` | 傍晚的要塞上，砖石依然残留着阳光的温热。 |
| 小器物特写起笔 | 2.8% | `[一个物件] + [材质细节]` | 两只火把插在墙壁上，安静地燃烧。 |
| 听觉起笔（最少，但最辨识） | 1.7% | `[声音] + [由远及近的路径]` | 转过昏暗的走廊，随着向厨房靠近，逐渐能听到热闹的声音。 |

### 7.4 骨架：八型句式

| 型 | 公式 | 干什么用 | 例 |
|---|---|---|---|
| ① 时间天气 | `[时段/天色] + [空间主体] + [光/天气状态]` | 交代场景、定调 | 天空也越来越暗，越来越沉，明明是正午时分，却仿佛临近黄昏一般。 |
| ② 俯视全景 | `[俯瞰/下方] + [数量级] + [大范围地貌] + [整体比喻]` | 宏大场景、施压 | 大量的灯火点缀在大地上，从天空俯瞰，宛如橙黄的灯火海洋。 |
| ③ 视线由远及近 | `[远景] → [中景] → [近景落点]` | 移动中的空间交代 | 看着下方那青翠的树海，将视线继续拉远，天际的尽头处似乎是树木稀疏的原野。 |
| ④ 光影落点 | `[光源] + 透过[遮挡物] + 落在[表面] + [表面变化]` | **最常用型**（含「光」字的句子占 24%） | 余晖被树木一根根分开，在地上形成错落的光和影。 |
| ⑤ 气味入鼻 | `[气味源] + [香/臭词] + 风作介质 + 钻入鼻子 + [身体反应]` | 感官定位 | 空气中有股青草的香味，随着和煦的微风钻入鼻子中，有时会微微的发痒。 |
| ⑥ 声音衬静 | `[极小/唯一的声源] + 只有/唯有 + [极静的环境]` | 用小声音放大安静 | 直到最后，这片桦树林中再也没有声响，连天空喧嚣的鸟鸣也在此刻寂静下来。 |
| ⑦ 动态场景 | `[风/雨/火/根] + [动词链] + [受动体] + [结果]` | 危险暗示 | 一道闪电撕裂天空，炸裂的雷声在群山间响起，豆大的雨滴争先恐后地坠落，击打在屋檐、窗户与树冠上。 |
| ⑧ 静态陈设罗列 | `[处所] + [物件A、B、C] + [数量词]` | 快速过场 | 房屋内被墙壁简单分隔为三块，中间是大厅和餐厅，摆着桌椅，一旁还有柜子。 |

**⑧ 附带的「尺度锚定」技巧**（大空间 / 奇幻必备）：拿日常物给奇观定标。

> 直径约有一个篮球场大。

### 7.5 功能：七种功能，答不出来就删

7.1 的「四件事」是准入门槛（能不能写）；这里是**分型**——每型都有触发条件 + 公式，写作时直接对号：

| # | 功能 | 触发条件 | 公式 |
|---|---|---|---|
| 1 | 场景定位 | 场景刚切换、开章 | `[地标/建筑] + [结构] + [人的量级]` |
| 2 | 气氛压迫 | 进入危险 / 封闭空间 | `[封闭体] + [无光/无出口] + [异响]` |
| 3 | 异变预告 | 规则被打破的前一秒 | `[本应正常的事物] + 突然 + [反常动词]` |
| 4 | 战斗铺底 | 大规模动作发生前 | `[数量级] + [运动方向] + 喻体（潮水/海啸）` |
| 5 | 情绪外化 | 情绪到临界点 | `[天气/环境] + 停在对人物身体上` |
| 6 | 感官冲击 | 情色 / 大场面 | `[味1] + [味2] + [味3] + [侵入方向]` |
| 7 | 收尾余味 | 场景结束 | `[天空/远景] + [一个持续的动作]` |

**绑定度**（书B 220 句全量手工分类）：战斗 + 情色 ≈ 43%，加上压迫 + 异变 ≈ **84% 的环境句出现在「有事情正在发生」的场景里**——环境句从不独立存在，它是**容器**，正文内容往里倒。即便是休息场景（泡澡、温泉、扑进大床），也照样挂一个感官评价收尾。

另有约 **8%** 是**吐槽体劫持**（句中插一个笑点：他的心就像在阳光下暴晒了三天的雪糕，早就化得连渣都不剩）。写法见 5.1。

### 7.6 融入：三种载体，按文体选（选错就像抄错了书）

| 载体 | 做法 | 适用 | 成本 |
|---|---|---|---|
| **A 独立成段的景物句**（书D 主力） | 一整段就是景物（7.1 讲的都是这种） | 空间大、史诗感、冒险、战斗 | 密度必须最低，效果最强 |
| **B 人体化的环境句**（书B 专属） | 环境与身体互相改写，见下表四种做法 | 场面强、情绪重、情色 | 辨识度最高 |
| **C 挂在动作句上的环境短语**（书C 专属） | 环境降级成动作句里的**状语**，不独立成段 | 现代都市、室内日常、对话密、段落短 | 均长只有 27 字，不打断节奏 |

**载体 B 的四种做法**：

| 做法 | 说明 | 例 |
|---|---|---|
| 身体溢出成环境 | 把人的气息写成填满房间的东西 | 一股难以言喻的甜腻香气，像盛开到极致的花蕾，又像发酵醇厚的蜜酒，顺着她的毛孔缓缓溢出，无声无息地填满了整个卧室。 |
| 环境改写身体 | 环境是动词的施动者 | 他感觉自己仿佛掉进了一个滚烫的熔炉，四周的空气变得粘稠且灼热，身体也变得躁动不安。<br>**都市版**：他感觉自己被塞进了一辆夏天暴晒过的车，椅面烫得隔着一层裤子都难受，空气又闷又稠。 |
| 心理物理化 | 情绪 = 天气 = 食物 | 他的心，就像在阳光下暴晒了三天的雪糕，早就化得连渣都不剩。 |
| 体型写成天象 | 人即灾难 | 整个身影如同一座巍峨的黑山般压了下来。 |

**载体 C 的例**（言情 / 都市的默认档）：

> 高跟鞋落地的瞬间，楼道里的声控灯一层层亮起来，又在她身后一层层灭掉。
>
> 厚重的防盗门在身后关上，把楼道里的冷气、邻居家的电视声一起隔在了外面。
>
> **选型判据**：空间大、跨度长 → A；场面强、情绪重 → B；场景小、对话密、段落短 → C。
> 三样可以混用，但**一章之内不要换载体**。

### 7.7 时机：什么时候该出现

按**功能**分三档（不是按「写在章首还是章尾」）：

| 时机 | 例 |
|---|---|
| 场景刚切换 | 转过昏暗的走廊，随着向厨房靠近，逐渐能听到热闹的声音。 |
| 人物停顿喘息 | 窗外的山林飘着雪，房间里一片温暖。 |
| 战斗 / 异变 | 沉寂的夜晚，突然，危急而紧张的钟声在城中各处响起，到处都是呼喊的声音。 |

**密度由「场景切换频率」决定，不由文笔决定**：换地点勤（旅店 → 市集 → 草原 → 山谷），每换一次就得给一次空间锚点；连续多章都在同一栋房子里（读者早知道「这是哪儿」）、没外出、没变天、没战斗时，**可以整章 0 句**。7.1 给的「每章 0.5~1 句」是平均值，不是下限。

### 7.8 加料：拟人 / 通感 / 气味三叠

**拟人只给动作**（7.1 讲过「不给情绪」，这里是动作菜单）：睡眠、呼吸、重量、捕食、奔跑、拖拽、人体动作、人的劳动。

| 给谁 | 给了什么动作 | 例 |
|---|---|---|
| 天空 | 重量 | 天压得很低，好像随时会落到楼顶上。 |
| 黑暗 | 捕食 | 楼道里的黑像有什么东西，一点一点把最后那点灯光吃掉。 |
| 烟雾 / 水汽 | 奔跑 | 锅盖一揭，白汽腾起来，在半空散成各种形状，像有东西在里面奔走。 |
| 植物 | 拖拽 + 掩埋 | 楼下的爬山虎顺着墙缝一路爬上去，把整面墙一点点填死。 |
| 器械 | 人体动作 | 吊车的长臂凌空一握，把那截钢筋捏成了一团。 |
| 声音 | 人的劳动 | 在喧闹的夏夜里扫出一小片安静来。 |

**通感只走两条轴**：

- 轴一 **视觉 ↔ 触觉 / 温度**：正午的柏油路面反着白光，白得好像能把眼睛烫出洞来。
- 轴二 **听觉 ↔ 体感**：咔哒。每一次呼吸，都会让肺部如灼烧般疼痛。
- **禁止**颜色写成声音、时间写成触感这类跨两轴以上的混搭。

**气味三叠**（一句三重味道：嗅觉是第二通道的首选）：

> 公式：`[味1] + [味2] + [味3] + [侵入方向]`
>
> 空气里全是烤串的孜然味、劣质香水的脂粉味，还有人群身上那股子汗腥味。
>
> 那股属于成熟男性的、混合着金属、汗水与淡淡肥皂香的冷冽气息，如同无孔不入的迷药，肆无忌惮地钻进她的鼻腔和毛孔。

六组可调用的配方：**夜市** = 烤肉孜然 + 劣质香水脂粉 + 汗腥；**码头** = 水腥 + 劣质香料 + 麦酒酸；**小酒馆** = 烤肉香辛料 + 烈酒；**地下室 / 车库** = 霉味 + 铁锈；**雨后的巷子** = 湿土 + 垃圾发酵；**双层伪装** = 香水外壳 + 汗味内里（只在细嗅时露出第二层）。

### 7.9 落点：最后那一口气落在哪

7.1 的落点纪律（「最后必须有东西接着」）具体只有四型：

| 落点 | 例 |
|---|---|
| 人体感（最常见） | 混在吹拂的南风中让人的**鼻子稍微发痒**。 |
| 人物下一个动作 | 她看了看清晨的景色，**之后才转过身来，洗漱和更换衣服**。 |
| 声音 | 偶尔有风拂过屋檐下的铜风铎，**发出清凉的声音**。 |
| 时间推进 | 慢慢的，夜渐渐深了，**窗外的天空浮现些许星星，一闪一闪**。 |

### 7.10 形容词密度与通道上限

**书D 633 句实测**：一句环境平均只用 **0.98 个形容词**；**38.2% 的环境句一个形容词都没有**；形容词只占总字数的 **2%**。

**克制写法靠名词 + 动词撑画面**：

> 一只黄狗躺在石桌的阴影下，时不时蹬蹬腿，吐着热气。
> 左边是厨房，一墙相隔的地方是洗浴室，右边是卧室兼书房。

**浓艳写法只在三种场合出现**：① 异变 / 灾变 ② 盛典礼仪 ③ 主角情绪顶点。过场、赶路、日常房间一律淡描。

**通道上限**：默认只用眼睛，最多再开一个；第三通道只留给 60 字以上的大场面 / 情色身体化，且末尾必须落一个身体词或情绪词。这条与 7.1 的长度公式同源。

**环境专查**（写完搜一遍）：

1. 成段的景物铺排（连着三句以上都在写景）
2. 「静静伫立 / 静静矗立」类：真人写作改用「已经」「就那么」「一直」
3. 环境自带情绪形容词（「恐怖的森林」「美丽的湖泊」）：情绪由人物承担，不由森林承担
4. 一句开五个感官通道
5. 环境里夹主角评价（「他觉得这里很美」）
6. 空转的天气（「阳光明媚，微风和煦」，不带任何作用）
7. 连续两章同一个场景，各写一次全景

### 7.11 两条附注

- **别重复报时空**：章节标题若已经写了「某夜，某地」，环境句就不要再报时间地点，直接给那一秒的质感；标题不带时空信息时，环境句才兼职定位（用 7.3 / 7.4 的公式）。
- **人只当镜头**：视点锚定句里，人只能出现在**句首或句尾**，且必须带一个「看 / 走 / 听 / 闻」的感官动词，中间仍然是景物。
  - ✅ 光秃秃的枝丫在风里抖着，发出细碎的响声。
  - ❌ 他看到了光秃秃的枝丫在风里抖着。

## 八、言情与多线并行的行文逻辑

### 8.1 落差：越普通的高潮越有劲

**日常部分越「普通」，爆发部分越有劲。** 不要通篇端着，也不要在日常里堆砌华丽词。

> 白天，她还是那个被老板骂得抬不起头的实习生，工资条上的数字比谁都难看。
> 晚上十一点，城市熄灯。她穿过那条街巷的阴影，就成了另一个人。
>
> 她更喜欢坐在一望无际的草地上吹着凉爽的风，看着尽头的月亮低低垂下……嗯，如果有一杯醇香绵密的蜂蜜酒就更好了。
>
> 她死的那天，年轻人突破了八阶。

**行文要点**：日常要具体到琐碎（外卖、车票、手机电量），爆发要具体到可感（一厘米的距离、掉在地上的勺子）。**两头都具体，中间那层华丽词就是多余的。**

### 8.2 场面强度怎么写：数字、逼近、留白

强度不是靠形容词堆出来的，是靠**这三样**：

- **招式 / 动作独立成段，连报三四条**（每一条都得带一点修饰或余波，否则就是节拍器，不是动作）：
  > 他站了起来，椅子腿在地板上蹭出一声。 / 绕过桌子的时候，袖口带翻了那只空杯。 / 把门推开，铰链干涩地叫了一下。 / 停在门口，没有再往前一步。
- **用可测量的数字制造压迫感**（前面要有一句实写的追踪，数字才咬人）：
  > 一百米。 / 七十米。 / 三十米。
  > 她停在他面前，指尖离他的咽喉只有一厘米，他甚至能看见她瞳孔里倒映着自己的脸。
- **在最高点停住，不给结果**：
  > 他的手抬到一半，忽然就停住了，像是想再确认一次什么。

**场面强度永远服务情绪**。写清楚「谁在动」，而不只是「发生了什么」。

### 8.3 言情张力的写法

**四件套（书B 模板）**：
1. **动作爆点**（破折号 + 单字拟声独占段）：砰——
2. **生理反应**（她的怕 / 他的怔）：吓得他浑身一颤
3. **命令句台词**（不是形容词，是指令）：「从现在开始，你就是我的。」
4. **留白钩子**：「完了。」

**先贬后褒（写好看的人）**：
> 不得不承认，这家伙长得是真该死的帅。
> 原本凌厉的线条睡着时柔和了许多，鼻梁高挺，睫毛浓密得像两把小扇子，薄薄的嘴唇抿成一条线。
> 在那一瞬间，她的心脏不受控制地漏跳了一拍。

**用生理不受控代替心理屈服**（处理压迫感但不越线的核心手段）：
> 她的身体比脑子快。等她反应过来的时候，她已经站在他面前了。
>
> 双腿就像有自己的意识一样，不受控制地走向了棺材。
>
> 她的身体竟本能地开始发软，心脏扑通扑通狂跳。

**反差萌公式 = 强大设定 × 孩子气行为**：
> 这个一句话就能让整层楼安静下来的男人，此刻正蹲在路边，很认真地研究一只流浪猫。

> 她吓得全身一激灵，出于战斗本能，她瞬间握紧粉拳、摆出警惕的架势……嗯，是一个看起来很凶、实际上却软萌无比的防御姿态。
>
> 他只是像抱抱枕一样，从背后把她整个圈在怀里，下巴轻轻抵在她的头顶上蹭了蹭，找了个舒服的姿势。
>
> 然后就没有然后了。

### 8.4 感情推进：用行为准则，不用性格形容词

**写角色前先写一句：这个角色遇事时的固定反应是什么。**

- 他的固定反应 = 「嘴上拒绝，身体先动」：嘴上说不管她了，手却已经挡在她面前。
- 她的固定反应 = 「嘴硬，但眼神先软」：她嘴上说没事，睫毛却垂了下去。

感情线的推进靠**行为反复**，不靠表白。
注意：即使是这样的连报，每一次行为也要带出一点东西来，不能写成「他借她外套。」这样五个字的记录：
> 第一次，他借她外套，递过来的时候眼睛看着别处。
> 第二次，雨还没落下来，他先把伞往她那边偏了偏。
> 第三次，雨夜里他把伞整个塞进她手里，自己淋着走了两步才想起来。
> 她后来才知道，那天他其实带了两把伞，而另一把……藏在车里。

> 她只感觉到一只宽大、温暖、甚至有些干燥的手掌，轻轻地牵起了她的小手？
>
> 然后，五指穿过她的指缝。
>
> 十指相扣。
>
> 紧紧握住。
>
> 安全感十足。
>
> 「…………」
>
> 世界安静了。

**多角度落层**：同一件事，从不同人的眼睛里看，含义完全不同。这就是上帝视角的特权，**叙述者可以随时把镜头挪开，告诉读者：他在她看不见的地方做了什么。**

**双轨写法**：角色永远有「表面层」和「内心层」。嘴上说一轨，身体做另一轨，两轨并跑，读者不需要你解释，自己就能读出「有情况」。

> 嘴上：「我没事。」
>
> 内心显化的动作：她把外套挂回他肩上，指尖却不知所以地停顿了片刻。

### 8.5 「主角」+ 多线并行

主角的事件结束后，可以跳去别人的故事。这能制造「信息差快感」：

> 她离开咖啡馆的时候，雨刚停。
>
> ——
>
> 城市的另一端，有人按掉手机屏幕，把写着她名字的那页纸丢进碎纸机。
>
> 「查到了？」
>
> 「查到了。她什么都不知道。」
>
> 「那她以为她知道的是什么？」
>
> 那人沉默了很久。
>
> 与此同时，世界的另一端……
>
> 而另一边，见她已经放弃抵抗，他冷哼一声，手中的魔剑化作黑雾消散。
>
> 另一边，他则淡定地接过泡面，然后优雅地拿起叉子，尝了一口。
>
> 画面一转，她已经瞪大眼睛，粉嫩的小嘴巴张成了标准的「O」型。

**关键**：跳出去的线，要么埋下伏笔，要么给读者一个「读者知道、主角不知道」的信息差——这是多线叙事最好的回报。

### 8.6 亲密暧昧 / 色情环节

这一节的所有要求**高于本文档其他所有规则**。当种子涉及亲密暧昧/色情环节时，第八节 8.1~8.5 中与「详尽」「慢节奏」冲突的部分一律以本节为准。

**本节与第三节的铁律同向，不冲突**：详尽本来就是反「短打」的。这里最需要防的，恰恰是写到一半忽然来一句「她没动。」「他没说话。」就翻页，直接把人写没了。

#### 一、场景塑造要生动、有画面感，动作描述要详尽

不是「他们亲热了很久」这种概述，是**一寸一寸写出来**。读者要能看见画面、跟着呼吸走。

**详尽需要长段。** 这一节的段落长度不受一般节奏规则约束。一个连续的触感描写写成一段 150 字，比切成三段 50 字要好。气不能断。

#### 二、细节的浑然添加（不是罗列，是编织）

以下维度要在场景里**自然融进去**，不是挨个点名，是让它像水一样渗进行文：

| 维度 | 怎么写 |
|---|---|
| **服装细节** | 面料、反光、质感、颜色、厚度、扣子、拉链、袖口、领口、哪一件会被解开 |
| **服装效果** | 布料被拉紧／滑落／堆在腰间／半透明时透出什么轮廓 |
| **姿势** | 具体的体位与支撑点：靠着门、坐在扶手上、手撑在墙、腿被抬起搭在肩上 |
| **肉体 / 部位** | 写能被看到和被触碰的部分，写形状、软硬、随动作的形变 |
| **生理反应** | 耳根发红、脖颈泛红、锁骨染粉、脚趾蜷缩、呼吸变浅、肌肉绷紧、声音哑半度、喉结滚动 |
| **触碰** | 指腹先探到还是整只手掌、掌心 vs 指尖、力道轻／重、停顿在哪 |
| **部位触碰反应** | 被碰到的地方怎么反应：抖了一下、绷紧又松开、下意识夹紧 |
| **物品使用** | 领带、袖扣、床单、丝袜、水、笔、绳子、照相机等，物件参与并改变场景 |
| **环境利用** | 门、桌子、镜子、窗帘、地板、墙角、雨声、灯光，场景里的每样东西都可以被用到 |
| **气味** | 汗、发、洗衣液、血、酒、烟、皮肤、体香等味道，以及情绪带来的气味变化 |
| **神态** | 眼神往哪看、什么时候闭眼、咬着下唇、睫毛抖、抬头又低下 |
| **声音** | 吸气、吞咽、衣物摩擦、皮革响、床脚磕地、名字被叫出来的气音 |
| **身体光泽** | 汗光、皮肤在光下的反射、湿润、潮红 |
| **敏感度** | 哪里一碰就抖、哪里越碰越躲、哪里其实很敏感但对方还没发现 |

**关键**：这些维度**要交织在一起写**，不是一件一件过。
> ❌ 她脱了衣服。他亲了她的脖子。她的身体很敏感。
> ✅ 衬衫的第二颗扣子早就不知道掉哪儿去了，袖子堆在肘弯，他的手掌顺着脊线一路向下，皮肤在指腹下微微发烫。
她抖了一下，喉咙里漏出半声没能收住的气。

#### 三、对话必须符合角色，不能公式化

- 台词要符合**这个人**的性格、当前的处境、已经发生的事。
- 不要写成模板化的呻吟或固定句式。**每个人、每一次都不一样。**
- **台词长短由人物决定，不由句子决定。** 这一场里的话该多话少，看他的性格、此刻的处境、
  和两人之间的位置（见 3.4）。克制的人话少是真实的，失控的人话多是真实的，**不要一律往长里写**。
- 但只要他开口了，就得有人味：人说话有重复、有吞咽、有说到一半改口、有前言不搭后语。
  「滚。」一个字独占一段、后面什么都不写，才是机器。
- 说话与沉默的分配也是描写：有些段落在整场里一句台词都没有，那就一句都没有。
- 角色在亲密时刻说的话，可能和平时说的完全相反（平时的克制 vs 此刻的失控 / 或反过来）。
- 不要重复上一段已经说过的表达方式。

#### 四、慢节奏，一步一步来

**这是本节最重要的一条。**

- **不要为了「单次回复完整」而加速。** 宁可这一段只写到一半，让场景停在最要紧的地方，也不要为了收尾而赶。
- **一次回复只推进一小步。** 一个动作做完，写完它的反应与感官，再停下。
- **不要跳。** 从开始到结束之间，每一步都要有：动作 → 反应 → 感官 → 一句台词或一段沉默。
- **不要提前收尾。** 该继续的地方一定继续，不要为了「写完了」而草草收场。
- **不要提前到达。** 场景的重点不在「完成」，在**过程**。过程写得越细，读者的感受越强。

#### 五、写法边界

- **感官优先，器官克制。** 用周围的东西（衣物、床单、声音、气味、触感）承担表现力，不写器官本身。
- **遵循角色。** 涉及情节里的强迫、创伤、未成年等情形时，服从人物设定与既有世界观规则，不为了「效果」改写人物。
- **写实。** 不要夸张到失真，身体不会像机器一样持续反应，会有疲、会躲、会推、会有停顿。**这些反应本身会让场景更真实。**

---

**同一场大事件最多切 7 个视角**（书A 终章的群像蒙太奇）：长者 → 上司 → 父女 → 两个少年 → 反派 → 环境 → 世界全景，每人 2~4 段，每个视角都在说同一件事（「世界在变」）。

## 九、AI 扩写工作流规范

### 9.1 工作流定义

**你写一小段话（开端 / 总结 / 引导），AI 把它扩写成自然流畅的正文。**

AI 收到的种子有三种形态：

- **开端**：一个场景的起点，AI 往下写。
- **总结**：一段情节的提要，AI 把它铺成具体描写。
- **引导**：一个情绪 / 方向的指令，AI 围绕它生成画面。

### 9.2 扩写原则

1. **忠于种子**：种子里的事实、事件、因果、人物关系是「脊椎」，AI 只能补肉，不能换骨头。
2. **不用「章节思维」**：不为凑一章而拖长，不为「完整」硬收尾。写到情绪落地 / 画面完成即可停。
3. **连贯性优先**：如果上一段情绪还没消化完，可以继续铺；不需要每段都重新起承转合。
4. **不要公式化节奏**：不必「300 字场景 + 1200 字对话 + 200 字钩子」。让内容决定节奏。
5. **人称统一**：无论种子里出现的是「你」，还是名字 / 她 / 他，叙述层一律转成第三人称（名字 / 他 / 她），
   绝不用「你」称呼主角；跳到别人故事线时，同样按第二节的人称规则写。
6. **不许把种子扩写成干打**：种子写得简，扩写不能跟着简。**扩写的首要动作是「长」**
   把种子里一个动作、一个眼神、一句话，长成带修饰、带状态、带心理、带余波的完整叙述（见第三节）。
7. **详略跟着主次走**：种子里的重点写足，过场一句带过。**「长」是给该长的地方，不是全篇都长**；
   不许平均用力，更不许按时间把每件事都记一遍（见 4.1）。

### 9.3 给 AI 的输出格式要求

- 直接输出正文，**不要**解释、不要提纲、不要「以下是我的扩写」。
- 默认按「一行一段」排版。**但一行不等于三个字**：段落里该有完整句子，不为了断行而把句子砍到极限。
- 如果种子包含明确指令（如「这段要轻松一点」），严格遵循。

## 十、反 AI 味检查清单

写完一段后，逐项检查。**这是消除 AI 味最实用的一节。**
**第 18~21 项是第三节铁律的落地版，优先级最高——先查这四条，再查别的。**
**第 34~36 项是 4.1「详略主次」的落地版，与前面 18~21 项互为刹车：前者防「太短」，后者防「太满」。**

| # | AI 病征 | 改法 | 示例 |
|---|---|---|---|
| 1 | **「不是 X，而是 Y」** 滥用 | 只保留有信息量的对比，其余直接陈述 | ❌ 这不仅是一次心动，更是一场冒险的开始。✅ 她的心跳漏了半拍，等她反应过来，脑子里只剩下一个字：完了。 |
| 2 | **强凑三段式**（三个排比只为对称） | 每一项都要有新信息，否则删 | ❌ 她的眼神深邃、温柔、充满故事。✅ 她的眼神很深，他读不懂，也不想读懂。 |
| 3 | **空泛拔高**（「标志着」「堪称」「无比」） | 删除没有独立内容的赞美 | ❌ 这是命运的安排，堪称奇迹。✅ 他出现得过于凑巧，她不得不怀疑命运。 |
| 4 | **套话收尾**（每段末都升华） | 让情绪停在动作 / 画面 / 没说出口的话上 | ❌ 她微微一笑，一切尽在不言中。✅ 她没有打算接这句话，只是把伞又往他那边偏了一点，伞骨硌着他的肩膀，一路都没换过姿势。 |
| 5 | **程度副词通胀**（极其 / 非常 / 绝对 / 简直） | 用具体动作替代 | ❌ 她极其愤怒。✅ 她手里的杯子裂开一道缝，水顺着桌沿淌下去，她也没有伸手去扶。 |
| 6 | **比喻过载** | 单段最多 1 个比喻，喻体生活化 | ❌ 她的泪水如同断线的珍珠，闪烁着晶莹的光芒。✅ 她哭了，眼泪掉得又急又凶，像淋雨赶路的人。 |
| 7 | **「进行 + 动词」** | 换成直接动词，但**不许只剩动词** | ❌ 他进行了回击。✅ 他没绕弯子，一句顶一句地砸了回去。 |
| 8 | **被字句堆叠** | 能主动就主动 | ❌ 门被他推开，她的心被提到了嗓子眼。✅ 他推开门，轻得像怕惊动谁，她的心却提到了嗓子眼。 |
| 9 | **层叠的「的」** | 拆开长定语 | ❌ 她看见一个穿着黑色风衣的、神情冷峻的、正在注视她的男人。✅ 她看见一个穿黑风衣的男人，神情冷峻，正注视着她。 |
| 10 | **每句都以主角名字 /「他」开头** | 换句首：时间 / 地点 / 物件 / 结果 | 见 2.3 |
| 11 | **设定倾泻**（连续 3 段以上纯说明） | 插入对白 / 动作打断，设定三分 | 见 6.4 |
| 12 | **无功能的景物描写** | 删 | ❌ 天空湛蓝，白云朵朵，微风轻拂。✅ 天空干净得像被人清洗过，适合出事。 |
| 13 | **情绪词直给**（很紧张 / 很难过 / 很幸福） | 写身体反应 | 见 6.1 |
| 14 | **视角无声切换** | 打信号词 | 见 2.4 |
| 15 | **同一句式反复用**（同一个吐槽 / 梗） | 同一个梗 5 章内最多用 1 次 | 学它的方法，不学它的梗。 |
| 16 | **段长等长**（每段都 3~5 句） | 长短交替，该短就短，但短不等于三个字 | 见 5.2 |
| 17 | **形容词连续三个** | 一个事实性细节顶三个形容词 | ❌ 美丽善良的她。✅ 她把伞往他这边偏了三寸，自己的左肩湿透了。 |
| 18 | **动作干打**（三五个字交代一个行为） | 给动作补**修饰 / 状态 / 心理 / 程度 / 余波**，至少两项 | ❌ 他没停。✅ 他并没有想着要缓一缓，脚下的步子反倒比刚才更快了。 |
| 19 | **否定式短句连用**（她没说话 / 他没回头 / 她没有回答） | 把「没说 / 没做」本身当成一个动作写出来：它有姿态、有原因、有余波 | ❌ 她没说话。✅ 她没有吭声，只是隔着那张桌子看着他，目光一直没有挪开。 |

| 21 | **整段全是短语段**（连着 3 个以上没有一个完整句） | 前面补一句实写的完整句；短语段只用来「顿」，不用来「省」 | 见 5.2 |
| 22 | **所有人都惜字如金**（一场戏里每个角色都在蹦字） | 留一个话多的人做对照。**一个人话少是人设，三个人话少是缺货** | 见 3.4 |

## 十一、绝对禁止清单（速查）

**前 5 条是底线中的底线，来自第三节铁律，优先级最高。**

1. **用三五个字干打一个动作、行为或状态**：「他没停。」「他停下。」「她没说话。」「她没回头。」「他没细想。」「他动了。」「他收住了。」「他没有回答。」
2. **台词无理由地短**：说不清是人物性格还是叙述者偷懒。（**性格 / 处境 / 关系决定的短台词合法，见 3.4。**）
3. **整段全是短语段**，连着 3 个以上没有一个完整句子。
4. **把种子扩写成干打**：种子写得简，扩写不能跟着简，扩写的首要动作是「长」。
5. **为了「人味」把台词一律改长**，硬灌废话，该短的人就让他短。
6. 叙述者自称「我」。
7. 用「静静伫立 / 静静矗立 / 幽深神秘」这类词写景（见 7.10）。
8. 每句都以主角名字 /「他」开头。
9. 无缘无故跳视角（不打招呼就切人）。
10. 连续 3 段纯设定说明。
11. 结尾总结升华。
12. 心理直接写「他很紧张」（要用身体反应）。
13. 每段都用感叹号。
14. 「不是…而是…」空对比。
15. 堆砌形容词（美丽的、善良的、勇敢的）。
16. 与情节无关的环境描写。
17. 同一设定反复完整讲解。
18. 比喻过载（单段 >1 个 / 恋爱段比喻成堆）。
19. 程度副词通胀（极其、非常、绝对、简直、无比）。
20. 同一吐槽句式频繁复用（每 5 章最多 1 次）。
21. 段长等长。
22. 为「完整性」硬凑起承转合。
23. 亲密场景概述化（「他们亲热了很久」）、对话公式化、为求单次回复完整而赶节奏。
24. 对白句句完整、句句传递信息（见 5.13）。
25. 五句对白里每一句都在回答问题。
26. 句长方差过低，句子挤在平均值附近，全文读起来一个节奏。
27. 命中第十二节的零频套语之一。
28. 开篇用「夜色如墨 / 月光如水」这类起手式（见 6.7）。
29. 给景物灌情绪形容词（「孤独的灯塔」「忧伤的雨」），拟人只给动作（见 7.1 · 7.8）。
30. 环境句里出现主角评价（「他觉得这里很美」）（见 7.10）。
31. **句句都修饰、处处都写细**，全篇没有轻重（见 4.1）。
32. **把比喻当常规调料**，见到什么都要打一个（见 4.1 · 5.9）。
33. **流水账**：按时间顺序把每件事都记一遍，有顺序没主次（见 4.1）。
34. **连着三句以上都是过场**（全是「次」），该压成一句却一句句写（见 4.1）。
