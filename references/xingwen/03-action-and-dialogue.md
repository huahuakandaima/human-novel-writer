> 第二节管「谁在说」，本节管「说得像不像人」。
> 它**压过后面所有关于节奏、短句、段长的技法**：第四节、第五节那些技法，都是在「已经像人」的前提下才谈得上的；一旦违反本节，节奏再好也是 AI 味。
> **但「写足」不等于「句句都写足」**：该写足的地方写足，该一句带过的地方就一句带过——详略怎么分，见 4.1。

### 3.1 病症：把一个活人写成了符号

AI 最大的破绽在这里：它爱把一个真人做的事，压缩成三四个字。看上去干净、克制、惜字如金，
实际上是把人写成了机器零件。**这些句子有一个共同点：除了「发生了什么」，什么都没有。**

| ❌ 干打（举例） | ✅ 应该怎么写（仅仅是示例） |
|---|---|
| 他没停。 | 他并没有想着要缓一缓，脚下的步子反倒比刚才更快了。 |
| 他停下。 | 门外传来的声音让他停下了脚步 / 他开始减速，慢慢停了下来。 |
| 她没说话。 | 她没有吭声，只是隔着那张桌子看着他，目光一直没有挪开。 |
| 她没回头。 | 她并没有回头，只是把脚步放慢了些，让他跟得从容一点。 |
| 他没细想。 | 他没有细想 / 他没怎么细想 |
| 他动了。 | 他到底还是动了，手比还脑子快，先一步替他抢来了答案。 |
| 他收住了。 | 他还是把后半句咽了回去。/ 他并没有继续加快速度，渐渐收力开始放缓。 |
| 他没有回答。 | 他没有立刻给她回答，只是把手插回裤袋，直直盯着她的眼睛。 |
| 她同意了。 | 她算是点了头，动作轻得谁都能看出来她很不情愿。 / 「行啊，我同意了。」/  |
| 他拒绝了。 | 他摇了摇头表示拒绝 / 他直接拒绝了她 / 「我不同意。」说完他一刻没停转身就走了。 |
| 两人沉默了。 | 两人都沉默了，谁都没有先开口。 |
| 她生气了。 | 她把杯子往桌上一顿，水都溅了出来，这次她是真的有些生气了 / 她冷着脸，一看就是生气了 |

**右边不一定要更长**：它们的最低标准只是「把话说完整」：谁在做什么、什么状态、什么态度，不再是电报。写到「脚下的步子反倒比刚才更快了」这种细度当然好，写到「她点了点头表示同意」只要不再像机器，也算数；当然，在一些表达上用人物的话来补充更好。
**只有「她点了头」这种光秃秃的动词是不行的**——但也不要把「补全」变成另一种公式，该短的人就让他短，短得有理由就行。**关键是别让句子只剩一个动词。**

### 3.2 为什么这是 AI 味的核心

- **短到极限的句子就像是节拍器。** 读起来不连贯、严重缺人味就是这么来的。
- **这种病会传染。** 一段里出现一次「他停住了」，整段的语感就往下掉一档。
- **对话里最容易暴露，但要先分诊**：这是叙述者偷懒，还是这个人物本来就惜字如金？判据见 3.4。

### 3.3 补全手法：给每个动作补上「动作」以外的东西

写完一个动作，先问自己一句：**这句话除了「做了什么」，还少了什么？**
从下面几项里**至少补上一项，最好两项**；**最低限度也要做到「换个说法 / 明确化」**——
就是不能让它只剩一个光秃秃的动词（对照 3.1 表里的「她点了点头表示同意」，那种程度已经算数）：

| 补什么 | 怎么补 | 例子 |
|---|---|---|
| **修饰**（快慢 / 轻重 / 犹豫 / 含糊） | 给动词加副词，或把动作塞进一个定语里 | 她**轻轻地**摇了摇头，摇到一半又突然停住 |
| **状态**（身体 / 手边的东西此刻是什么样） | 动作发生时，手、袖口、杯子、烟头是什么样子 | 他把行李箱的拉杆又往下按了一格，指节压得发白 |
| **心理**（在想什么 / 怕什么 / 赌什么 / 想瞒住什么） | 叙述层可以直接进角色的内心，不必用「他想」包一层 | 他并不打算让她等太久，可话到嘴边，他还是决定说得更慢一点 |
| **程度 / 时长**（多久、几次、多急） | 把一个瞬间拉长，或者压一下 | 她隔了很久才回答，久到他以为她根本不会回答了 |
| **余波 / 结果**（动作之后留下了什么） | 让动作有落点、有代价、有痕迹 | 她急忙收住脚，可还是把他绊倒了 |
| **换个说法**（同义替换 / 反着写 / 换施动者 / 换施动时刻） | 不重复同一个动词 | ❌ 她不同意 → ✅ 她把头偏开不看他，视线落到窗外去了 |

**台词同理**：人说话会带语气词、重复、吞咽、反问、说到一半改口、临时换措辞：

> ❌ 「滚。」
> 她走了。
>
> ✅ 「滚。」
> 话从她牙缝里硬挤了出来，她已经受不了了。

**唯一不能一刀切的是台词**：它长还是短，由这个人物的**性格、处境、关系**决定，判断标准在下一小节。

### 3.4 台词：长还是短，由人物决定，不由句子决定

**台词的长度不是「标准」，是人物属性。** 它由三件事决定：

| 决定什么 | 影响什么 |
|---|---|
| **性格** | 有人天生话多，有人一辈子惜字如金。话少是他的**人设**，不是缺陷 |
| **处境** | 被震住、语塞、疲惫、垂死、被拿捏的时候，人本来就说不出长句 |
| **关系** | 亲疏、地位、戒备、试探，决定话里有多少余地、有多少刺 |

所以**不能一刀切地要求台词变长**。真正要禁的只有一种：**叙述者偷懒。**

> **一条判据就够了：一个角色可以全程惜字如金，但叙述层不能惜字如金。**
> 人物话少是设定，读者能感觉到这个人的性格；旁白话少是偷懒，读者只会觉得文本没人味。

#### 一、该短的台词：短得有理由

三种合法形态，每一种都必须自带「证据」：

| 形态 | 什么时候用 | 必须给的证据 | 例 |
|---|---|---|---|
| **人设型** | 这个角色本来就寡言 | **全段贯彻**他每一次开口都短；并且**周围必须有话多的人做对照**，反差才成立 | 他：「嗯。」／「不用。」<br>她：「你怎么才回来——都两个小时了，汤我都热了三回。」<br>他脱下厚重的外套挂在衣架上，蹲下身脱鞋，全程没有一句解释。<br>又是这样，她叹了口气。<br>「微波炉。」说完她就回卧室了。 |
| **语塞型** | 被震住、说不下去 | 生理表现（喉结、吞咽、停顿、呼吸）+ **叙述者把没说出口的那部分补出来** | 「你……」她张了张嘴，后半句到底没能说出口。 |
| **关系型** | 生分、对抗、试探 | 短句带刺；**改口和没说完的部分承担信息** | 「不用了。」她顿了顿，「……我一个人可以。」 |

> ⚠️ **人设型必须「独一份」。** 同一场戏里如果每个人都惜字如金，那就不是人设，是缺货。
> **一个短句角色 + 一个啰嗦角色**是写法；**三个短句角色**是偷懒。

#### 二、该长的台词：长得有内容

话多不等于水。长的地方必须有「东西」：追问、试探、绕、掩饰、词不达意、说给自己听。而且不一定非得一句话全部说完，你可以把一句拆成几个连续的段列在一起。

> 「你今天回来得怎么比平时晚了两个小时？」
>
> 「我不是要问你去了哪儿，我只是想说......」
>
> 「我下午给你熬的那锅汤热的我已经尝不出味了。」

这不是把句子拖长，是**把她没说出口的东西说出了形状**。

#### 三、兜底手法：短台词必须被「托住」

极短台词**可以有**（「嗯。」「……算了。」），但要被**一样东西托住**，三选一即可，不能一个都没有：
**一个动作**（「嗯。」他把手里的伞收了，伞骨在台阶上磕出一声）／
**一个神态**（「不用。」她眼睛落在别处，落了很久）／
**对方的动作反应**（「滚。」／他愣了两秒，转身把门带上，比来时轻）。

#### 四、三问判据

1. **这个人物少说话，读者能感觉到他的性格吗？** 能 → 合理简短。
2. **这段台词短，是因为这个人物此刻说不出 / 不想说，还是因为我懒得写？** 是「我懒得写」 → 干打，必须改。
3. **短台词说完之后，有没有人接、有没有反应、有没有余波？** 三样都没有 → 翻页太快了。

**短句怎么断行、什么时候允许 10 字以内，见 5.2。**
