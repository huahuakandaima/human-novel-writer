# 小说写作文笔指导规范（AI 扩写工作流 · 第三人称）

> **本文件是 human-novel-writer skill 的「行文文笔规范」轨道主文件**（来自《小说ai行文规范》，贴吧作者"我不记道哇"原作，2026-10-07 并入）。
> **优先级（2026-10-07 用户裁定）：本规范与 skill 旧规则（`anti-ai-rules.md`、`human-writing-style.md` 等）冲突时，以本规范为准**，旧文件中的冲突条目已按本规范改写。
> 加载后的执行顺序：① 读「规则优先级」定冲突裁决 ② 读「硬性红线速查」的两条判据（干打管下限、主次管上限）与五组量化红线 ③ 确认第二节称呼契约（第三人称、禁「你」也禁「我」）与第三节铁律 ④ 按第九节工作流扩写，写完过收尾检查两遍。种子涉及亲密暧昧环节时必须额外执行 8.6 与收尾检查的条件检查。句式模板、环境骨架、对白范例等技法再去翻同目录分册。
> 同目录分册导航见 `00-index.md`。

本规范由四本原书逐章分析总结而成（叙述者插话体 31 万字 / ACG 弹幕体 109 万字 / 网络轻吐槽体 76 万字 / 群像编年体 382 万字）。只讲**怎么把句子写好、怎么把行文和对话把控住**，不涉及剧情套路与设定。

**一句话总纲：AI 写的不是「章节」，是「一段有人味的话」。**

**第二节管「谁在说」，第三节管「说得像不像人」。** 先记这两件；其余全是技法，违反这两条，技法再好也没用。

**用户写一小段（开端 / 总结 / 引导），AI 负责扩写成自然流畅的正文。** 所以这份规范约束的是「怎么写」，不是「写多少」——它服务一个情绪 / 一个画面 / 一条因果链，**不受章节管控，不为凑一章而牺牲连贯性，节奏不必公式化**。

引文示例里的身份、场景、行为、世界观仅供学习句子的结构与节奏，与用户设定无关 —— 学的是写法，不是内容。遵守用户的世界观。

⚠️ **本版是第三人称规范。** 叙述层的主角用**名字或「他 / 她」**，具体用哪个由用户的设定决定（有名字就优先用名字，避免读者每段都要重新认出主角）。**两个词一律禁用：「你」**（会被读成第二人称、或读成在跟读者说话）和**「我」**（那是叙述者，叙述者从不自称「我」）。

本规范的示例沿用原书写法：**「他」和「她」是小说里的角色，不固定指向主角**。同场出现两个人时按上下文分辨谁是主角 —— 镜头焦点所在的那个就是。学的是**句子结构和节奏**，身份分配由用户的世界观决定。

## 硬性红线速查（全部常驻，无需翻分册）

这一节是**量化约束**，原书散在第五、六、七、八节里。任何写作场景都适用，与用不用得上技法无关。

### 干打判据（最高频的病，优先查这条）

> **每一个动作句，在「做了什么」之外至少要有两项。**
> **其中一项必须是「换个说法 / 明确化」。**

病征的定义不是句式，是**信息量**：

> 这些句子的共同点：**除了「发生了什么」，什么都没有。**

所以不要按句形排查 —— 否定式开头（`他没停`）、光秃秃的单动词（`他动了`）、用结论代替行为（`他同意了`）只是同一病的不同表象，**还会有你没见过的第四种**。

**补全六项**（原文顺序，缺一即算未补全）：

| 补什么 | 怎么补 |
|---|---|
| **修饰** | 副词 / 把动作塞进定语（快慢、轻重、犹豫、含糊） |
| **状态** | 手、袖口、杯子、烟头此刻是什么样 |
| **心理** | 在想什么 / 怕什么 / 想瞒什么（叙述层可直接进内心，不必用「他想」包一层） |
| **程度 / 时长** | 多久、几次、多急；把瞬间拉长或压一下 |
| **余波 / 结果** | 动作之后留下了什么（落点、代价、痕迹） |
| **换个说法 / 明确化** | 同义替换、反着写、换施动时刻 —— **这一项不可省**，它保证句子里确实有新信息，而不只是在原句尾巴上挂修饰 |

**三条容易漏的：**

1. **补了不等于违规，但要看补了什么** —— 一个句子可能字面上仍像 ❌ 那一栏的某个开头，但只要确实补全了两项以上，就是**合规的**。判据是信息量，不是像不像范例。
2. **不要拿范例的形状当模板** —— 范例只示范病，不示范解法。照着 ❌ 那栏的字面去躲，往往会写出「另一种同形态的开头」，病没治好，只是换了个马甲。
3. **用结论代替行为最容易漏检** —— 「（某人）同意了」「（某人）生气了」这类语法完整、长度合规，但跳过了整个过程，六项一项都没补。

**台词同理**：人说话会带语气词、重复、吞咽、反问、说到一半改口、临时换措辞。台词的最低标准是**不只剩一个动词或一个意思**。

### 主次判据（管上限：治「全都写满」）

> 上一条治「全都太短」，这一条治「全都写满」。**两条同向，合起来才完整。**
> **详略由「主次」决定，不由「句子」决定** —— 不是每句话都要修饰，不是每个细节都值得写细。

**一个片段的笔墨分配：**

| 位置 | 给多少笔墨 | 怎么写 |
|---|---|---|
| **主**：情绪爆点 / 转折 / 关键动作 | 写足 | 至少补两项（见上节），长一点没关系 |
| **中**：主线需要的必要信息 | 写清楚 | 完整的句子，但不加装饰 |
| **次**：过场、重复信息、读者早知道的事 | 一句带过，或干脆不写 | 拆成五句就是流水账 |

**主次三问**（写完一段先分主次，再改字）：

| 问 | 主 | 次 |
|---|---|---|
| 这句在推动什么 | 主线事件、关系变化、情绪拐点 | 只是在填时间、填空间 |
| 读者需要记住它吗 | 需要 | 不需要 |
| 它在段里的位置 | 爆点、转折、关键动作 | 过场、过渡、读者早知道的事 |

**「不写」也算一种。** 该跳的地方直接跳过去，读者不会觉得少了；什么都写，读者反而什么都记不住。

**四条禁令：**

1. **不许句句都修饰一下。** 修饰是重音，句句都加等于没有重音。一段里只在本段重音处修饰，其余白描。
2. **不许什么都写得很细。** 详写是一种注意力分配；全都详写＝没有重点，读者会累，读到真正的爆点反而没感觉。**判据：这段如果只留三句话，该留哪三句？** 留下来的才是主。
3. **不许动不动就打比方。** 比喻是重武器，一段最多 1 个；**凡是不值得写足的地方，也不配给它一个比喻。**
4. **不许流水账。** 流水账 = 有顺序，没主次。三种长相：
   - **时间流水账** —— 起床、洗漱、挤地铁…一件事一件按钟点记
   - **动作流水账** —— 动作链本身没错，错的是**链上每个动作一样重**
   - **对话流水账** —— 一来一回全是信息，像会议记录

**一条判定方法**：给这段每一句在心里标「主 / 次」。

- 全是「主」→ 没分主次，回头砍
- 连着三句以上都是「次」→ 压成一句
- 只有一两处「主」、其余中/次 → 正常段落

> ⚠️ **详略不是按字数平均分的。** 一段里可以有 150 字的详写，也可以有 5 个字的带过，**差别本身就是重点**。
> ⚠️ **这一条不是给干打开后门。** 「一句带过」指的是**过场**，不是把该写足的动作压成三个字。干打是把该写足的动作写没了，流水账是把不该写足的事写满了，**两个都要改**。

### 段落长度

| 红线 | 说明 |
|---|---|
| **交代动作、行为的句子，不得单独放进 10 字以内的段落里** | 这是防干打的核心量化线 |
| 10 字以内**只允许五种**：① 时间/数字（`一秒。`）② 拟声词（`嗡——`）③ 否定/反问式顿（`不是巧合。`）④ 意象对仗收尾三连 ⑤ 标签清单式短句（紧跟其后**必须**补一个完整行为句） | 这五种是修辞装置，不算干打。**除此之外任何 10 字以下的段落都不合法** |
| 极短台词可以独占一段 | 前提是符合 3.4 三种合法形态、且被动作/神态/对方反应托住 |
| **叙事推进：一个场景一段，不超过 150 字** | 详尽描写不受此限 |
| **超过 200 字还在加形容词 → 停下**，回到 5.10 重挑结构 | |
| **长短段都是倾向，不是铁律。段落该长的时候就得长** | 别机械执行 150 字 |
| **段长要有方差，不能每段都 3~5 句** | 把最长句砍一半，或把两个短句合成一个长句 |

### 比喻

| 红线 | 说明 |
|---|---|
| **单段最多 1 个比喻** | 恋爱场景 3~5 段才放 1 个，其余白描 |
| **每个角色全书比喻不超过 5 个**，且要「专属化」（她像猫就一直像猫） | |
| **唯一越界的是「生僻」**：读者要想一下才明白的喻体 = AI 味 | 落在哪个圈层由题材定：都市/日常 → 游戏、外卖、猫、泡面；奇幻/古代 → 山川、兵刃、市集、酒食。**言情优先选生活游戏向** |

### 标点

| 红线 | 说明 |
|---|---|
| **默认用逗号连缀**，顿号只允许出现在「他/她的原话」和快速罗列里 | 叙述层是书面感的全知叙述者 |
| **吐槽、心理戏用问号**；爆发、告白、高光才用感叹号 | 「这也能叫运气？」比「这也能叫运气！」更有调侃味 |
| **疑问句应是感叹句的五倍左右** | 书A 全书 31 万字只用 284 个感叹号、1456 个问号，情绪依然饱满。这是叙述者吐槽能成立的技术基础 |

### 环境描写

| 红线 | 说明 |
|---|---|
| **一句最多两个感官通道，视觉默认占一个** | 第三通道只留给 60 字以上的大场面/情色身体化，且末尾必须落一个身体词或情绪词 |
| **长度 = 感官通道数 × 15~20 字** | 1 通道 15~30 字（转场）／2 通道 30~60 字（主力）／3 通道 60~90 字 |
| **禁止跨两轴以上的感官混搭**（颜色写成声音、时间写成触感） | |
| **拟人只给动作**（睡眠、呼吸、重量、捕食、奔跑、拖拽、人体动作、人的劳动），**绝不给情绪** | 不写「孤独的灯塔」「忧伤的雨」 |
| **独立成段的环境描写，绝不夹在对白中间** | 「对白→环境→对白」出现 0 次 |
| **主语是景物，不是人** | 九成以上环境句以景物开头；用人称只做视点锚定，且人必须在句首或句尾 |
| **浓艳写法只在三种场合出现**：① 异变/灾变 ② 盛典礼仪 ③ 主角情绪顶点 | 过场、赶路、日常房间一律淡描 |
| **一个场景里纯短语段不超过 2~3 个，且不连着超过 3 个** | 纯短语段指没有主谓的短句块（「一秒。」「嗡——」） |
| **一块环境是「一句」，常态是「两句一组」（静 + 动）**；**连着三句以上都在写景，样本中出现 0 次** | 独立环境句每章 **0.5~1 句**；场景切换那一章可给 2 句 |
| **环境密度由场景切换频率决定，不是下限** | 换地点勤（旅店→市集→草原）每换一次给一次空间锚点；连续多章同一地点、没外出没变天没战斗时，**可以整章 0 句** |
| **同一场大事件最多切 7 个视角** | 书A 终章群像蒙太奇：每人 2~4 段，每个视角都在说同一件事 |
| **写景占篇幅 8%~12%，是配角** | 感官优先级 视觉 > 听觉 > 嗅觉 > 触觉 > 味觉；视觉独占五成 |
| **情绪不由景物承担**，环境里不夹主角评价（「他觉得这里很美」→ 删） | 情绪由人物承担 |

### 内容与结构

| 红线 | 说明 |
|---|---|
| **一个设定只准完整讲一次**，后续只准引用代号 | 设定三分法：切成三块，每块之间插一句对白/动作打断 |
| **连续 3 段以上纯设定说明 = 设定倾泻** | |
| **开篇三行原则**：前三行内必须交代谁/在哪/正在做什么，至少给两个 | 读者读三行还进入不了状况就会走 |
| **一场戏内视角切换不超过 2 次** | 跳去别人故事线要先交代「谁 + 在哪」 |
| **预知与回望一个片段最多用一次** | 第二次要有明显升级；日常推进片段里不用 |
| **同一吐槽句式 / 同一个梗，5 章内最多用 1 次** | 学它的方法，不学它的梗 |
| **每段都用感叹号** ❌ | 见标点红线 |
| **叙述层出现「你」或「我」** ❌ | 「我」是叙述者（且叙述者从不自称「我」）；「你」会把读者拉进故事。主角只用名字或「他/她」 |

### 长句崩坏四症状（自查）

| 症状 | 表现 | 修法 |
|---|---|---|
| **连接词断链** | 三个以上逗号分句之间没有逻辑词 | 补「然后/但/所以/等到」 |
| **形容词代替动作** | 「美丽的、温柔的、坚定的目光」 | 换成他做了什么 |
| **指代不清** | 长句里出现两个「他」 | 第二次改用「那个人」或具体部位 |
| **没有落点** | 写完不知道停在哪 | 末尾加一个具体动作或物件 |

判断方法：**把长段的最后一句单独读一遍。** 不能独立成立、也不能自然接下一段，说明这段散了。

## 二、叙事总契约（称呼契约）

**全知的第三方叙述者（上帝视角）。** 三个位置必须分清：

| 位置 | 是什么 | 设定 |
|---|---|---|
| **叙述者** | 讲故事的人，不属于任何角色 | 全知、有性格、会吐槽、会预知；**永远不以「我」自称** |
| **主角** | 故事跟着走的那个人 | 叙述层用**名字或「他 / 她」**称呼；**绝不用「你」** |
| **读者** | 旁听者 | 站在故事外，听叙述者讲主角的故事 |

> 核心概念叫**「称呼契约」**：叙述者是那个说话的人，主角是那个被叙述的人，读者只是旁听。
> **叙述层唯一禁止的两个词是「你」和「我」。** 「我」属于叙述者，且叙述者从不自称「我」；「你」会把读者拉进故事，或把主角降格成读者的替身 —— 两个都不允许。
> 所以主角是**一个完整的角色**，不是读者的替身。他可以有读者没有的经历、性别、能力。

**主角是叙述的落点，不是叙述的眼睛。** 叙述者是全知的，主角有盲区、会想错、有些事根本不知道 —— 这些正是叙述者存在的理由。

### 人称规则表

| 场景 | 叙述层用什么 | 例子 |
|---|---|---|
| 主角在场、动作、外貌 | **名字 / 他 / 她**（用户设定里给名字就优先用名字） | 林述推开那扇门，走廊的灯一盏接一盏亮起来。 |
| 主角的心理 | **他 / 她** 的内心，直接写，不加「他想」 | 他忽然意识到，她说的「下次见」不是客套。 |
| 主角有名字时 | **名字优先**，尤其是首次出场、切换场景、多人同场 | 林述把伞收了，伞骨在台阶上磕出一声。 |
| 其他角色的动作 / 心理 | **他 / 她 / 名字**，要能分辨出是谁 | 她靠在窗边，指尖的烟明明灭灭，她其实在等他回头。 |
| 完全跳去别人的故事线 | **他 / 她 / 名字**，看这条线是谁 | 城市的另一端，有人拨通了电话：「她不见了。」 |
| 叙述者本人 | **禁止「我」** | 用「他后来才知道」「说来可笑」这类话代替。 |

**两条硬规则**：

1. **叙述层的主角用名字或「他 / 她」，永远不用「你」**。只要主角在当前画面 / 事件里，叙述就用名字或「他 / 她」。
2. **同场多人时不要让读者猜**。两个以上角色在场，名字 / 代词要能分辨；实在分不清就换标记（外貌、动作、位置），而不是靠「他 / 她」硬猜。

> ⚠️ **第三人称不等于每句都要带名字。** 中文小说的常态是「名字 + 他/她 + 零指代」交替。一句里出现两次「他」就会指代不清（见 5.11），这是本版最需要盯的一条。

### 主角代词的使用纪律（避免疲劳）

主角用「他 / 她」用多了同样会腻。三条纪律：

- **不要每句都以主角的代词开头**。用时间、地点、物件、结果做句首。
  - ❌ 他看见她。他心跳加速。他不知道该说什么。他低下头。
  - ✅ 走廊尽头，她站在那里。灯光斜斜地打下来，心跳声变得格外清晰，他低下头，忘了自己要说什么。
- **让主角的代词出现在句中、句尾**，和句首的其他主语轮换。
- **名字与代词交替**：一段里「他」出现两三次后，用一次名字重新锚定，读者不会走神。

### 视角跳转

主角的世界允许**多线并行**：他的事件结束后，镜头可以跳去其他地方，讲别人的互动和故事。但跳转必须让读者看得懂：

| 跳转类型 | 信号 | 例子 |
|---|---|---|
| 场景 / 时间跳转 | 独立成段的破折号 | 林述走出咖啡馆，雨刚好停了。 / —— / 三天后，老宅的灯还亮着。 |
| 空间并行 | 与此同时 / 另一边 / 画面一转 / 另一头 | 与此同时，城市的另一端，有人把写着林述名字的那页纸丢进碎纸机。 |
| 视角跳转 | 换行 + 明确主语 | 他按掉手机屏幕，沉默了很久。 |

- 一场戏（对话 / 拉扯 / 冲突）内视角切换**不超过 2 次**
- 跳去别人故事线时**先交代「谁 + 在哪」**，不要让人猜
- 切回主角时，可以用一个动作或一个场景标记点自然接回来，不必解释

### 叙述者可以做什么

这是第三人称叙述最大的优势：**叙述者是有存在感的**。叙述者可以：

1. **预知与回望**（言情利器）：

   > 那时候他还不知道，这个总在深夜给他发消息的女人，三个月后会替他挡下那颗子弹。此刻他只知道，屏幕又亮了：「睡了吗？」

2. **一句话交代背景**（借「三句口径」句式，详见 6.4）：

   > 有些人在这个圈子里是被公开谈论的，官方叫他们「专家」，民间叫他们「疯子」，而他，两者都不算。

3. **评论命运**（片段末的意象对仗）：

   > 他抬头望天。 / 整栋楼的人都在抬头望天。 / 只有她，在看他。

**但预知是重武器。** 它一旦高频使用就会迅速变成狗血，读者会开始预判而不是被击中。

- **一个片段最多用一次**，且只在情绪确实需要时才动用（悬念、反差、宿命感）
- 日常推进的片段里不要用
- 同一段故事里，第二次使用要有明显升级（从「他不知道」变成「他早就知道」）

## 三、铁律：动作与台词，不许三五个字干打

> 本节压过后面所有关于节奏、短句、段长的技法。第四节第五节那些技法都是在「已经像人」的前提下才谈得上；一旦违反本节，节奏再好也是 AI 味。

### 病症：把活人写成了符号

AI 最大的破绽是**把一个真人做的事压缩成三四个字**。看上去干净克制，实际上把人写成了机器零件。这些句子的共同点：**除了「发生了什么」，什么都没有。**

| ❌ 干打 | ✅ 至少不是电报 |
|---|---|
| 他没停。 | 他并没有想着要缓一缓，脚下的步子反倒比刚才更快了。 |
| 她没说话。 | 她没有吭声，只是隔着那张桌子看着他，目光一直没有挪开。 |
| 他没细想。 | 他没有细想 / 他没怎么细想 |
| 他动了。 | 他到底还是动了，手比脑子快，先一步替他抢来了答案。 |
| 他收住了。 | 他还是把后半句咽了回去。 |
| 她同意了。 | 她算是点了头，动作轻得谁都能看出来她很不情愿。 |
| 她生气了。 | 她把杯子往桌上一顿，水都溅了出来，这次她是真的有些生气了。 |

**右边不一定要更长。** 最低标准只是「把话说完整」：谁在做什么、什么状态、什么态度，不再是电报。写到「脚下的步子反倒比刚才更快了」这种细度当然好，写到「她点了点头表示同意」只要不再像机器，也算数。

**唯一不能容许的是「她点了头」这种光秃秃的动词。** 但也不要把「补全」变成另一种公式 —— 该短的人就让他短，短得有理由就行。**关键是别让句子只剩一个动词。**

### 补全手法：至少补两项

写完一个动作问自己：**这句话除了「做了什么」，还少了什么？**

| 补什么 | 怎么补 | 例子 |
|---|---|---|
| **修饰**（快慢/轻重/犹豫/含糊） | 给动词加副词，或把动作塞进定语 | 她**轻轻地**摇了摇头，摇到一半又突然停住 |
| **状态**（手边的东西此刻是什么样） | 动作发生时手、袖口、杯子、烟头什么样子 | 他把行李箱拉杆又往下按了一格，指节压得发白 |
| **心理**（在想什么/怕什么/想瞒什么） | 叙述层可直接进内心，不必用「他想」包一层 | 他并不打算让她等太久，可话到嘴边，还是决定说得更慢一点 |
| **程度/时长**（多久、几次、多急） | 把瞬间拉长，或压一下 | 她隔了很久才回答，久到他以为她根本不会回答了 |
| **余波/结果**（动作之后留下了什么） | 让动作有落点、代价、痕迹 | 她急忙收住脚，可还是把他绊倒了 |
| **换个说法**（同义替换/反着写/换施动时刻） | 不重复同一个动词 | ❌ 她不同意 → ✅ 她把头偏开不看他，视线落到窗外去了 |

最低限度也要做到「换个说法 / 明确化」。**台词同理**：人说话会带语气词、重复、吞咽、反问、说到一半改口、临时换措辞。

### 台词长短：由人物决定，不由句子决定

**不能一刀切要求台词变长。** 台词长度由三件事决定：

- **性格** —— 有人天生话多，有人一辈子惜字如金。话少是他的**人设**，不是缺陷
- **处境** —— 被震住、语塞、疲惫、垂死、被拿捏的时候，人本来就说不出长句
- **关系** —— 亲疏、地位、戒备、试探，决定话里有多少余地、有多少刺

> **一条判据就够了：一个角色可以全程惜字如金，但叙述层不能惜字如金。**
> 人物话少是设定，读者能感觉到这个人的性格；旁白话少是偷懒，读者只会觉得文本没人味。

**合法的短**（三种形态，每种必须自带「证据」）：

- **人设型** —— 本来就寡言。全段贯彻他每次开口都短，且**周围必须有话多的人做对照**，反差才成立
- **语塞型** —— 被震住。生理表现（喉结、吞咽、停顿、呼吸）+ 叙述者把没说出口的补出来
- **关系型** —— 生分、对抗、试探。短句带刺，改口和没说完的部分承担信息

> ⚠️ **人设型必须「独一份」。** 一场戏里如果每个人都惜字如金，那就不是人设，是缺货。
> **一个短句角色 + 一个啰嗦角色**是写法；**三个短句角色**是偷懒。

**合法的长**：话多不等于水。长的地方必须有东西 —— 追问、试探、绕、掩饰、词不达意、说给自己听。

**兜底手法**：极短台词（「嗯。」「……算了。」）可以存在，但要被一样东西托住，三选一即可：

- 一个**动作**（「嗯。」他把手里的伞收了，伞骨在台阶上磕出一声）
- 一个**神态**（「不用。」她眼睛落在别处，落了很久）
- **对方的动作反应**（「滚。」／他愣了两秒，转身把门带上，比来时轻）

**三问判据**：

1. 这个人物少说话，读者能感觉到他的性格吗？→ 能，合理简短
2. 这段台词短，是因为他此刻说不出/不想说，还是因为我懒得写？→ 后者必须改
3. 短台词说完之后，有没有人接、有没有反应、有没有余波？→ 三样都没有，翻页太快

## 四、行文逻辑：自下而上四层

不管写什么片段，永远自下而上写：

```
第4层  节奏层：段落怎么切、句长怎么配、何时单句成段
第3层  情绪层：这段服务什么情绪（暧昧/紧张/好笑/心疼）
第2层  视角层：镜头在主角身上，还是跳去了别人那里
第1层  事件层：谁做了什么，导致什么
```

**先想事件，再定视角，再定情绪，最后调节奏。** 绝大多数「AI 味」都是倒着写出来的 —— 先堆词藻，再补事件。

**反公式化节奏**：不要每次都是「场景交代 → 对话冲突 → 结尾钩子」。可以停在一个动作、一个画面、一句没说出口的话上。**连贯性 > 完整性** —— 宁可为上一段情绪的延续多写两句，也不要为了「一段完整的情节」生硬收尾。

### 详略主次

> **详见上方「主次判据」一节**（已常驻：主/中/次配比、主次三问、四条禁令、流水账三长相、主次标注法）。

## 五、句子层技术（要点）

> ⚠️ **标点纪律与比喻纪律的量化红线，已在「硬性红线速查」常驻**，本节不重复。

- **破折号插入语**是叙述者吐槽和后续解释的武器，**绝不滥用，少而精**。吐槽里可以直接用六个点「......」（比「……」更轻、更滑稽）
- **单句成段 / 短语成段**是节奏的核心武器，但**短是断行的结果，不是省字的理由**。一段里连着 3 个以上纯短语段，前面必须补一句实写的完整句
- **主语省略 + 动作短语连缀**、**长定语不带「的」套娃**、**四字短语插入**（把成语当逗号用）、**递进式短语成段**（情绪爆发）
- **对话标签**：能省则省，要加就缀一个动作或神态，**绝不用废标签**（「他愤怒地说」）
- **长句的五种合法结构**：动作链 / 感官叠加 / 因果链 / ……
- **长段分寸**：详尽描写就该用长段，一行一段不等于三个字

> 完整技法（八型句式、长定语套娃变体、对话标签变体、长句五结构详解、对白人味六病征）见 `05-sentence-craft.md`

## 六、内容层技术（要点）

- **用身体反应代替情绪词** —— 不写「她很紧张」，写「她第三次去摸口袋里的手机」
- **用具体动作代替程度副词** —— 不写「她极其愤怒」，写「她把杯子往桌上一顿，水都溅了出来」
- **心理描写 = 预期违背** —— 写「他以为…结果…」，而不是「他想了想」
- **设定投放**：寄生在冲突 / 对话 / 吐槽里，绝不集中讲解。连续 3 段以上纯说明 = 设定倾泻
- **人物出场**：外貌清单 + 一个爆点
- **记忆点系统**：让读者记住一个角色的具体习惯动作或口头禅
- **开篇段**：第一句不要「夜色如墨 / 月光如水」这类起手式
- **场景切换**：切换之后的第一句必须自足（读者不能靠上文猜）

> 详细写法见 `06-content-craft.md`

## 七、环境描写（核心纪律）

> ⚠️ **通道上限、密度公式、拟人边界、浓艳场合等量化红线，已在「硬性红线速查」常驻**，本节不重复。

**必须「有用」。** 答不出「这句环境在干什么」就删 —— 它只有七种正当功能：交代位置、渲染气氛、暗示时间、制造悬念、映衬情绪、埋伏笔、参与事件。

**三种载体按文体选**：写景与叙事交织 / 独立成段的场景切换 / 人物专注感知时的特写。选错就像抄错了书。

**落点**：环境句最后那一口气必须落在人物身上，不能停在景物。

> 详细写法（六种起笔、八型骨架、三叠加料、落点四型）见 `07-environment.md`

## 八、言情与多线并行

### 8.4 感情推进：用行为准则，不用性格形容词

**写角色前先写一句：这个角色遇事时的固定反应是什么。**

> 嘴上拒绝、身体先动 / 嘴硬、眼神先软 —— 感情线的推进靠**行为反复**，不靠表白。

- **每一次行为都要带出一点东西来**，不能写成五个字的记录（「他借她外套。」✗）
  - ✅ 第一次，他借她外套，递过来的时候眼睛看着别处。
- **多角度落层**：同一件事从不同人的眼睛里看，含义完全不同。**叙述者可以随时把镜头挪开，告诉读者：他在她看不见的地方做了什么。**

> 8.1 落差 / 8.2 场面强度三法 / 8.3 言情张力四件套 见 `08-romance-and-multiline.md`

### 8.6 亲密暧昧 / 色情环节（优先级最高）

> **这一节的所有要求高于本文档其他所有规则。** 种子涉及该场景时，8.1~8.5 中与「详尽」「慢节奏」冲突的部分一律以本节为准。
> **本节与第三节铁律同向，不冲突**：详尽本来就是反「短打」的。

**五条硬约束：**

1. **详尽，不概述。** 不是「他们亲热了很久」，是**一寸一寸写出来**，读者要能看见画面、跟着呼吸走。
2. **详尽需要长段 —— 段落长度不受一般节奏规则约束。** 一段连续的触感描写 150 字，优于切成三段 50 字。**气不能断。**（这一条豁免上文的 150 字上限）
3. **慢节奏，一步一步来。** 一次回复只推进一小步：**动作 → 反应 → 感官 → 一句台词或一段沉默**。**不要跳，不要提前收尾，不要提前到达** —— 重点不在「完成」，在**过程**。宁可只写到一半停在最要紧的地方，也不要为了收尾而赶。
4. **感官优先，器官克制。** 用周围的东西（衣物、床单、声音、气味、触感）承担表现力，不写器官本身。细节要**交织**着渗进行文，不是一件一件点名罗列。
5. **对话必须符合角色，不能公式化。** 台词长短仍由性格/处境/关系决定（见 3.4），但**只要开口就得有人味**（重复、吞咽、改口、前言不搭后语）。角色在亲密时刻说的话可能和平时完全相反。

> **这里最需要防的，恰恰是写到一半忽然来一句「她没动。」「他没说话。」就翻页，直接把人写没了。**

> 完整写法（十四维度细节表、写法边界）见 `08-romance-and-multiline.md`

## 九、AI 扩写工作流

**你写一小段话（开端 / 总结 / 引导），AI 把它扩写成自然流畅的正文。**

种子有三种形态：**开端**（一个场景的起点，往下写）/ **总结**（一段情节的提要，铺成具体描写）/ **引导**（一个情绪或方向的指令，围绕它生成画面）。

### 七条扩写原则

1. **忠于种子** —— 种子里的事实、事件、因果、人物关系是「脊椎」，只能补肉，不能换骨头
2. **不用「章节思维」** —— 不为凑一章而拖长，不为「完整」硬收尾。写到情绪落地 / 画面完成即可停
3. **连贯性优先** —— 上一段情绪还没消化完可以继续铺；不需要每段都重新起承转合
4. **不要公式化节奏** —— 不必「300 字场景 + 1200 字对话 + 200 字钩子」。让内容决定节奏
5. **人称统一** —— **叙述层一律用第三人称：名字或「他 / 她」**。无论种子里出现的是「你」、名字、还是别的写法，都转成第三人称；**「你」和「我」都不许出现在叙述层**。跳到别人故事线时，按人称规则表用该角色的名字或「他 / 她」
6. **不许把种子扩写成干打** —— 种子写得简，扩写不能跟着简。**扩写的首要动作是「长」**：把种子里一个动作、一个眼神、一句话，长成带修饰、带状态、带心理、带余波的完整叙述
7. **详略跟着主次走** —— 种子里的重点写足，过场一句带过。「长」是给该长的地方，不是全篇都长

### 输出格式

- 直接输出正文，**不要**解释、不要提纲、不要「以下是我的扩写」
- 默认按「一行一段」排版。**但一行不等于三个字** —— 段落里该有完整句子，不为了断行而把句子砍到极限
- 种子包含明确指令（如「这段要轻松一点」）时严格遵循

## 十一、绝对禁止清单（速查 34 条）

**前 5 条是底线中的底线，来自铁律，优先级最高。**

1. **用三五个字干打一个动作、行为或状态**：「他没停。」「他停下。」「她没说话。」「她没回头。」「他没细想。」「他动了。」「他收住了。」「他没有回答。」
2. **台词无理由地短** —— 说不清是人物性格还是叙述者偷懒。（性格/处境/关系决定的短台词合法）
3. **整段全是短语段** —— 连着 3 个以上没有一个完整句子
4. **把种子扩写成干打** —— 种子写得简，扩写不能跟着简
5. **为了「人味」把台词一律改长** —— 硬灌废话，该短的人就让他短
6. 叙述层出现「你」或「我」—— 主角只用名字或「他 / 她」
7. 用「静静伫立 / 静静矗立 / 幽深神秘」这类词写景
8. 每句都以主角名字 /「他」开头
9. 无缘无故跳视角（不打招呼就切人）
10. 同场多人分不清谁是谁（一句里出现两次「他」指代不清）
10. 连续 3 段纯设定说明
11. 结尾总结升华
12. 心理直接写「他很紧张」（要用身体反应）
13. 每段都不用感叹号
14. 「不是…而是…」空对比
15. 堆砌形容词（美丽的、善良的、勇敢的）
16. 与情节无关的环境描写
17. 同一设定反复完整讲解
18. 比喻过载（单段 >1 个 / 恋爱段比喻成堆）
19. 程度副词通胀（极其、非常、绝对、简直、无比）
20. 同一吐槽句式频繁复用（每 5 章最多 1 次）
21. 段长等长
22. 为「完整性」硬凑起承转合
23. 亲密场景概述化（「他们亲热了很久」）、对话公式化、为求单次回复完整而赶节奏
24. 对白句句完整、句句传递信息
25. 五句对白里每一句都在回答问题
26. 句长方差过低 —— 句子挤在平均值附近，全文读起来一个节奏
27. 命中零频套语之一
28. 开篇用「夜色如墨 / 月光如水」这类起手式
29. 给景物灌情绪形容词（「孤独的灯塔」「忧伤的雨」），拟人只给动作
30. 环境句里出现主角评价（「他觉得这里很美」）
31. **句句都修饰、处处都写细**，全篇没有轻重
32. **把比喻当常规调料** —— 见到什么都要打一个
33. **流水账** —— 按时间顺序把每件事都记一遍，有顺序没主次
34. **连着三句以上都是过场**（全是「次」），该压成一句却一句句写

## 收尾检查（每次写完）

**第一遍 · 红线（对照「硬性红线速查」）**

1. **逐个动作句数补全项** —— 在「做了什么」之外至少两项，其中一项必须是「换个说法/明确化」。**按信息量判，不按句形判**
2. **逐段标主次** —— 全是「主」就砍；连着三句「次」就压成一句。有没有句句都修饰、件件都写细
3. **10 字红线**：有没有动作句独占一个 10 字以内的段落？五种例外之外都是违规
4. **比喻个数**：单段最多 1 个；这个角色全书不超过 5 个，且喻体不生僻
5. **环境通道**：有没有一句开三个以上感官？末尾落身体词或情绪词了吗
6. **环境独立成段**：有没有把写景夹在对白中间？
7. **段落长度**：叙事推进有没有超 150 字？有没有超 200 字还在加形容词？
8. **标点**：顿号是不是只出现在原话里？感叹号是不是用多了？
9. **设定**：有没有连续 3 段纯说明？这个设定是不是讲了第二遍？
10. **第三人称用对了吗？** 叙述层有没有混进「你」或「我」？同场多人时分不分得清谁是谁？

**第二遍 · 内容（对照三大清单）**

11. **有没有干打？** 回到第 1 条重数一遍 —— 这一条最容易漏，因为第一遍可能只查了长度
12. **有没有写满？** 回到第 2 条重标一遍 —— 和上一条相反的两种病
13. **台词长短有理由吗？** 每个短句都能说出是性格/处境/关系，还是只是我懒得写
14. **零频套语命中了吗？** 对照上表
15. **环境句有用吗？** 答不出功能就删；有没有灌情绪形容词或主角评价
16. **句长有方差吗？** 是不是全挤在平均值附近
17. **长段散了吗？** 把最后一句单独读一遍，能独立成立或自然接下段吗

**条件检查 · 只在种子涉及亲密暧昧/色情环节时做（8.6 优先级最高）**

18. **有没有概述？** 出现「他们亲热了很久」这种概括就是违规，必须一寸一寸写
